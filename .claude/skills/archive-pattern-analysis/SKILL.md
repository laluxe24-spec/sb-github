# Xアーカイブ構成分析

**必ず`05_Projects/content/docs/archive_pattern_analysis.md`を読み、そこに書かれている手順(STEP1〜4)にそのまま従う。**このSKILL.mdでは内容を複製しない。

## 実行時にやること

1. `05_Projects/content/scripts/classify_archive.py`で全件の機械分類(STEP1)と層化サンプリング(STEP2)を実行する。
2. サンプルを2〜3個に分割し、Agent tool(`general-purpose`)で並列に深掘り分類させる(STEP3)。
3. 結果を集計し、構成・切り口の選択ルールを含む最終ドキュメントを`05_Projects/content/`に保存する(STEP4)。

## 注意点

- 目的はアーカイブの投稿をそのまま真似ることではなく、**今後の投稿生成で使える「型の引き出し」を増やすこと**。特に「対比型がデフォルト化する問題」の解消を優先する。
- 機械分類(STEP1)は全件対象、深掘り分類(STEP3)は層化サンプル(200件程度)のみに絞る。3000件超をすべてLLMで読むのはコストが高すぎる。
