# YouTube

`SKILL.md`の「動画の文字起こし」のやり方で、`01_Sources/04_YouTube`で実行する。

```bash
cd 01_Sources/04_YouTube
python3 scripts/transcribe.py "https://youtu.be/xxxxxxxxxxx"
```

- URLは`https://www.youtube.com/watch?v=...`または`https://youtu.be/...`
- 1本が長いので、文字起こしに数分〜数十分かかることがある
- 実践者のノウハウ動画(「月50万達成」系)は個人の体験談。ナレッジにする時は、発信者ごとの専用ファイルに入れる
