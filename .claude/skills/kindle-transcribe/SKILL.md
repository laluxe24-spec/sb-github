# Kindle文字起こし

Kindle本を`02_Sources/01_Kindle/scripts/`のスクリプトでスクショ→OCRし、`02_Sources/01_Kindle/data/<本のタイトル>/`に保存した上で、内容を`03_Knowledge/<該当ジャンル>/`の判断.md・行動.md・会話.mdに統合するスキル。

**詳しい手順は必ず`02_Sources/01_Kindle/docs/操作メモ.md`を読んでから、その手順通りに進める。**この操作メモには、スクショの撮り方・重複削除の2段階の方法・縦書き/横書きでのOCRスクリプトの使い分け・Knowledge統合の仕方・過去にハマったトラブルと対処法(座標計算、目次ページでの停止、章扉ページの誤検出など)が詳しく書かれている。ここでは全体の流れだけをまとめる。

## 手順の概要

1. **本を開く**: Kindleアプリで対象の本を開く。ユーザーが手元にいない場合は、操作メモ.mdの手順0に従いClaude自身がKindleライブラリを操作して開いてよい。
2. **キャプチャ**: `kindle_screenshot.py`でスクショを撮る(最終ページで自動停止するので、ページ数の指定は基本不要)。
3. **重複削除**: MD5完全一致→dHash近似重複、の2段階で重複画像を削除する。dHashで検出した候補は、章扉ページなどの誤検出が多いので**必ずReadツールで目視確認してから削除する**。
4. **OCR**: 縦書きなら`ocr_book.py`(tesseract jpn_vert)、横書きなら`ocr_book_horizontal.py`(macOS Vision)を使い分けて`本文.md`を作る。
5. **Knowledge統合**: `本文.md`(誤字混じりの生テキスト)を読み、本の核心的な考え方を抽出して`03_Knowledge/<該当ジャンル>/`の判断.md・行動.md・会話.mdに直接統合する。単体の`<本のタイトル>_考え方まとめ.md`は作らない。出典(本のタイトル・著者)を必ず明記する。分量が多いので、この読み込み・統合作業はAgentツール(fork)に任せて本体の会話コンテキストを汚さないほうがいい。
6. **後片付け**: Knowledge統合が終わったらスクショは削除してよいが、**削除前に必ずユーザーに確認を取る**(重複削除の自動実行とは違い、正常なページも含めた本体データの削除のため)。

## 注意点

- トリガーの指示があった時点で、上記の手順は逐一確認を取らずに自動で進めてよい(手順6のスクショ削除だけは例外)。
- OCRは「本の考え方が分かればいい」という方針で、一字一句の精度にはこだわらない。多少の誤字・重複・順序の乱れは気にしすぎずに先へ進む。
