# ナレッジQA(品質確認)

`knowledge-agent`スキルが作った03_Knowledgeの内容が、保存する価値のある形になっているかを確認するスキル。「正しいか間違っているか裁く」のではなく、「解析係の判断そのものを疑いすぎず、明らかにおかしい所だけ直す」役割。

**必ず`07_System/launchd/knowledge_review_prompt.md`を読み、そこに書かれている手順(git diffでの変更確認→会話系/行動系/要約系それぞれの確認項目→軽微な問題は直接修正・重めの問題はログに記録)にそのまま従う。**このSKILL.mdでは内容を複製しない(手順が更新された時に二重管理でズレるのを防ぐため)。

## 手動実行時の違い

- 手動で頼まれた時は「無人実行モード」の自己紹介文言は不要。秘書エージェント自身が今その場で同じ確認ロジックを使っている、という扱いでよい。
- プロンプト内の「gitへのcommit/pushはしない」「git diff/git log/git showの読み取りだけ使ってよい」という制限は、無人実行でも対話実行でも変わらず守る(このスキルの役割はあくまで確認であり、コミットや別のBash操作をする役割ではない)。
- `knowledge-agent`スキルの直後(同じセッション内)に呼ばれた場合は、そのセッションで何を新規作成・更新したかは既に分かっているはずなので、`git diff`は念のための確認として使えばよい。
