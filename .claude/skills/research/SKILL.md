# リサーチ(副業のための調査・分析)

りゅーじ君は分析のやり方を知らない前提で動く。何を調べるか・どんな切り口で見るかは、こちらで考えて提案する。

## 1. 始める前に

どのプロジェクト(副業)の話かを確認し、`04_Projects/<プロジェクト>/`のルールを読む(ゴール・リサーチの条件・投稿の形)。どのプロジェクトか分からなければ、りゅーじ君に聞く。

## 2. 何を調べるか決める

「〇〇について調べて」とざっくり言われた時や、何を調べるか決まっていない時は、先に調べる計画を出す。

1. ルールでゴールを確認する
2. ゴールに近づくために、今一番知るべきことを3つまで出す
3. それぞれ「何を」「どんな切り口で」「調べると何が分かるか」を1行ずつ
4. りゅーじ君が選んだものを調べる

## 3. どのファイルを読むか

| 何を | 読むファイル |
|---|---|
| Xのデータの分析・バズ探し・アカウント調査 | `X.md` |
| 自分の結果の振り返り(どの媒体でも) | `結果分析.md` |
| 02_Knowledgeへの残し方(ネタ・分析・成功と失敗・ノウハウ) | `残し方.md` |

新しい媒体(Threads・noteなど)を調べる時は、`X.md`と同じ形で`<媒体名>.md`を作ってから始める。

## 4. 共通ルール

- 決まった「見るところ」は最低ライン。差がありそうな観点は自分で足す。1つの見方で分からなければ、別の切り口で見直す
- 「なんとなく」は禁止。必ず数字で比べる
- 確かめたことと仮説を分ける。データに無いことは結論にしない
- 出典(URL・ファイル名など、どこから取ったか)を必ず書く
- ネットで調べる時は、3つ以上の情報源を本文まで読んで比べる。同じ検索を何度もループしない
- 専門用語を使わず、中学生でも分かる言葉で書く
- 他の人の投稿の文章をそのまま報告に貼らない。流れ・型・言い回しの特徴として書く

## 5. 報告の形(毎回これで出す)

1. 今回やった分析: 何を・どんな見方で調べたか
2. 分かったこと: 数字つき
3. 提案: 次に取り入れること(1〜3個。そのまま使える形で)
4. この分析の甘いところ・次に試したい別の切り口

成功 = りゅーじ君がこれを読んで「やる/やらない」をすぐ決められること。

## 6. 終わったら

- 分かったことを`残し方.md`のとおりに`02_Knowledge/`に残す
- 報告を秘書AIに返す。秘書AIはそれを見て戦略案(次に何をどう変えるか)を作り、りゅーじ君に出す
