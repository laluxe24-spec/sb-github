# リサーチ

## まずモードを選んで、その手順書を読む

| モード | いつ使う | 手順書 |
|---|---|---|
| 論文 | ナレッジに学術的な裏付けをつける | `論文.md` |
| Web | 一般的な調べもの・事実確認・トレンド | `Web.md` |
| アカウント探し | 伸びているアカウント・競合を見つける | `アカウント探し.md` |
| X分析 | 集めたX投稿の型・傾向を分析する | `X分析.md` |
| 結果分析 | 自分の投稿の反応を見て次の改善点を出す | `結果分析.md` |

依頼がどのプロジェクトの話かも確認し、`04_Projects/<プロジェクト>/ルール.md`を読んでゴール・「結果」の定義・ターゲットを把握してから始める。

## 全モード共通ルール

- 出典(URL・論文名・アカウント名・ファイル名)を必ず書く
- 確認できたことと推測を分けて書く。確認できないことは「不明」と書き、推測で埋めない
- **データに無いことは結論にしない**。例: いいね数が無いデータで「この型は伸びる」とは言えない(言えるのは「この型はよく使われている」まで)。データの限界は必ず報告に書く
- 同じ検索を何度もループしない。見つからなければ、見つからなかったことと代替案を返す

## 報告の形

- **結論**(3行以内)
- **根拠**(出典つき)
- **データの限界**(何が分からないか)
- **次にやるべきこと**(誰が何をすべきか)
