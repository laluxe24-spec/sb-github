## 1. アカウント探し(伸びているアカウント・競合を見つける)

1. `ルール.md`でターゲット・ジャンルを確認する
2. 候補を集める:
   - 集めている7アカウントの投稿の中の引用・メンション
   - Xの中での検索。`01_Sources/02_X/scripts/auth.json`(収集で使っているXのログイン情報)を使ってPlaywrightでXを開き、キーワード検索する。検索用のプログラムはまだ無いので、最初に使う時に`01_Sources/02_X/scripts/`に作る
3. 候補ごとに見る:
   - フォロワー数(こちらと近い規模の方が参考になる)
   - 最近伸びているか
   - 最近の投稿1本あたりのいいね・表示回数の平均
   - 投稿の頻度
   - ターゲットが同じか
4. 候補の一覧表を作り、1アカウントずつ「追う価値がある理由」を1〜2行で書いて、おすすめ順に並べる
5. 追加するかは秘書が決める。決まったらx-post-collectスキルで収集に加える

## 2. 伸びる型の分析

集めた投稿(`01_Sources/02_X/data/@<アカウント>/posts.json`)から、どんな型が伸びているかを出す。目的は投稿をそのまま真似ることではなく、投稿作りで使える型を見つけること。

**今のデータにはいいね数・表示回数が無い。** 数字が取れるようになるまでは、分かるのは「よく使われている型」まで。

### いいね数がある時(こちらが本来のやり方)
1. アカウントごとに、いいねが上位2割の投稿と下位2割の投稿を分ける(フォロワー数が違うアカウント同士を直接比べないため)
2. 上位と下位で、構成の型・テーマ・切り口・1行目・長さ・鍵カッコのセリフの有無を比べる
3. 複数のアカウントで共通して「上位に多いもの」を「伸びる型」とする

### いいね数が無い時(よく使われている型を調べる)
1. 全件を構成の型で機械的に分類して、割合を出す:
   ```bash
   cd .claude/skills/research/scripts
   python3 classify_archive.py
   ```
2. 型の割合に合わせて200件を選ぶ(少ない型も最低限入れる。`scripts/_sample_output.json`に出る):
   ```bash
   python3 classify_archive.py --sample 200
   ```
3. サンプルを2〜3個に分け、Agentで並列に1件ずつ「テーマ/切り口/具体性(抽象的なアドバイス・具体的な行動・セリフ・状況・心理)/心理学概念(はっきりある時だけ)」を分類させる
4. 合算して、型・切り口・具体性・テーマの割合と、使える型の一覧を出す

### 出すもの
- 伸びる型(または、よく使われている型)
- `ルール.md`の「投稿の形」をどう変えるべきかの案
