## データの場所と中身

- いつも追っている人: `01_Sources/02_X/data/@<アカウント>/posts.json`
- リサーチのために仮で集めた人: `01_Sources/02_X/候補/<プロジェクト>/@<アカウント>/posts.json`(毎朝の自動収集には入らない)
- 1件の中身: `text`(全文)・`created_at`・`parent_id`(スレッドの続きなら親の投稿ID)・`is_long`・`metrics`(views=表示回数・likes・reposts・replies・bookmarks・quotes)・`metrics_at`(数字を取った日時)
- アカウント情報: `profile.json`(`created_at`=アカウントを作った日、`history`=集めた時点ごとのフォロワー数・フォロー数・投稿数。新しいものが上)
- 集め方はcollectスキル(`X.md`)。自分で別のプログラムを作らない

Xで取れる数字は、表示回数・いいね・リポスト・返信・ブックマーク・引用。どれを重視するかはプロジェクトのルールで決める。

## 1. 集めたデータの分析(何がバズったか・なぜか)

1. 期間を決めて(普段は直近1週間〜1ヶ月)、分析する前にその期間を`collect_posts.js <アカウント> 1 --full`で取り直す(数字を最新にするため)
2. 本体(`parent_id`が無い投稿)と続き(`parent_id`がある投稿)を組にする。続きの読まれ率 = 続きの表示回数 ÷ 本体の表示回数
3. **同じアカウントの中で**、伸びた投稿(上位2割)と伸びなかった投稿(下位2割)を比べる(フォロワー数の差を気にしなくていいように)
4. 最低限見るところ: 1行目の言い回し・本体の切り方(どこで切って続きに渡しているか)・続きの読まれ率・テーマ・よく使う言葉・長さと改行・投稿の形(スレッドか1本か)・投稿時間
5. 複数のアカウントで共通していたら「伸びる傾向」、1人だけなら「その人の特徴」として書く

## 2. なぜフォロワーが伸びていないか(根本の原因)

数字の比較で終わらせず、「読んだ人がフォローしない根本の理由」まで掘る。伸びている人だけでなく、同じジャンル・同じ形なのに伸びていない比較用の人とも比べる。

1. まず並べる: 作ってからの月数・フォロワー数・1ヶ月あたりの増え方・投稿頻度・表示回数の平均・表示回数÷フォロワー数。「古いのに伸びていない」「新しいのに伸びている」のような差を見つける
2. 次の順で、どこで止まっているかを見る(読者がフォローするまでの流れ):
   - **見られていない**: 表示回数そのものが少ない → 1行目・テーマ・投稿頻度・投稿時間の問題
   - **見られているが読まれていない**: 表示回数はあるのに、いいね・続きの読まれ率が低い → 中身・切り方・読みやすさの問題
   - **読まれているがフォローされない**: 反応はあるのにフォロワーが増えない → 「この人を追う理由」が無い問題
3. 「フォローする理由が無い」は特に深く見る: 何の人か一目で分かるか(プロフィールと投稿のテーマが一致しているか)・テーマが散らばっていないか・他の人と何が違うか・続けて読みたくなる連続性があるか・キャラや視点があるか
4. 伸びている人と比べて、「伸びている人がやっていて、伸びていない人がやっていないこと」を根本の原因として出す。数字で確かめられたことと、投稿やプロフィールを読んで判断したこと(仮説)は分けて書く
5. 最後に、りゅーじ君のアカウントで同じ落とし穴にはまらないために何をするかを出す

## 3. バズ投稿探し・参考アカウントの入れ替え提案

1. ルールのキーワードでXを検索し、ルールの条件に合う投稿を探す(`search_posts.js`。**まだ無い。最初に使う時に作り、テストしてから使う**)
2. 条件に合う投稿を出したアカウントを候補にし、`候補/<プロジェクト>/`に直近1ヶ月を集める
3. 今追っている人と候補を、同じ物差しで比べる: フォロワー数・投稿数・条件を満たした投稿の数・表示回数(平均/最高)・表示回数÷フォロワー数・続きの読まれ率・投稿の形が合っているか・よく使うテーマと1行目の型
4. 「〇〇を外して△△を入れる」を根拠(数字)つきで提案する。入れるかはりゅーじ君が決める
5. 入れると決まったら、collectスキルで`data/`に移して収集リストに書く。入れないと決まった候補のデータは、りゅーじ君に確認してから消す

Xに制限されないように、1回の検索は1キーワード50件まで・合計300件まで。キーワードの間は少し休む。

## 4. 指定されたアカウントを調べる

「このアカウント調べて」と言われたら、3の手順2〜4と、2のなぜ伸びていないかの分析を、そのアカウントだけでやる。
