# X分析モード: 集めたX投稿の型・傾向を分析する

`01_Sources/02_X/data/`に集めた投稿から、「構成×切り口×テーマ×具体性×心理学概念」の傾向を出す。目的は投稿をそのまま真似ることではなく、投稿作りで使える型の引き出しを増やすこと。

**注意**: 今のデータにはいいね数・表示回数が無い。なので分かるのは「よく使われている型」までで、「伸びる型」は言えない。いいね数が取れるようになったら、反応の多い投稿と少ない投稿を比べる分析に切り替える。

## STEP1: 機械分類(全件)
```bash
cd .claude/skills/research/scripts
python3 classify_archive.py
```
全件を構成タイプ(対比型/短文型/箇条書き型/会話例型/番号リスト型/問いかけ型/その他)で分類し、割合を出す。一瞬で終わる。

## STEP2: 偏らないサンプルを作る
```bash
python3 classify_archive.py --sample 200
```
構成タイプごとの割合に合わせて200件を選ぶ(少ない型も最低限入れる)。`scripts/_sample_output.json`に出力される。

## STEP3: 深掘り分類(Agentで並列)
サンプルを2〜3個に分け、同じ数のAgent(`general-purpose`)に並列で渡して、1件ずつ次を分類させる:
- **テーマ**: 何について書いているか(初デート・LINE・告白など)
- **切り口**: どう伝えているか(NG行動・成功行動・意外な事実・女性側の受け取り方など)
- **具体性**: 抽象的なアドバイス/具体的な行動/具体的なセリフ/具体的な状況/具体的な心理
- **心理学概念**: はっきり根拠がある時だけ(心理的リアクタンス・損失回避・愛着など)。弱ければ「なし」

出力は「id: テーマ/切り口/具体性/心理学概念」の1行形式+200字程度の集計サマリー。

## STEP4: まとめて報告
全Agentの結果を合算し、構成・切り口・具体性・心理学概念・テーマの分布と、使える型の一覧を出す。投稿ルールに反映すべき点があれば「次にやるべきこと」に書く(ルールを書き換えるのは秘書)。
