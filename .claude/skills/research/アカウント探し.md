# アカウント探しモード: 伸びているアカウント・競合を見つける

1. プロジェクトの`ルール.md`で、ターゲット・ジャンル・ゴールを確認する
2. Web検索(「恋愛 X アカウント おすすめ」など)と、既に集めているアカウントの引用・リポスト・メンションから候補を集める
3. 候補ごとに次を見る(分かる範囲で):
   - フォロワー数と、最近伸びているか
   - 1投稿あたりのいいね・表示回数(反応率)
   - 投稿の型・頻度
   - ターゲットがプロジェクトと近いか
4. 候補ごとに「なぜ追う価値があるか」を1〜2行で書き、おすすめ順に並べる
5. 追加が決まったら、x-post-collectスキルで収集リストに入れる(追加するかは秘書が判断する)

XやInstagramはログインが必要で直接見られないことが多い。見られなかった場合は正直にそう書き、推測で埋めない。
