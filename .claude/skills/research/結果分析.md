# 結果分析(自分の投稿の振り返り・どの媒体でも共通)

週1回、プロジェクトの`投稿記録.md`を見て、次の投稿で何を変えるかを出す。

1. `投稿記録.md`から、まだ分析していない投稿を集める
2. 2つの差を見る:
   - **① Claudeの案 → りゅーじ君が実際に投稿した文**: どこをどう直したか。直し方にパターンがあれば、それがりゅーじ君の基準
   - **② 反応が良かった投稿と悪かった投稿**: 型・テーマ・切り口・1行目・長さなど、何が違うか
3. 「なんとなく良い」は禁止。違いは具体的に書く
4. 投稿が10本たまるまでは①を優先する(数字の差は偶然の可能性が高いから、②は「傾向」として控えめに書く)
5. 出すもの:
   - 次の投稿で試すこと(1〜3個)
   - `ルール.md`の変更案(どこをどう変えるか)
6. 分析した投稿には、`投稿記録.md`の「分析」を「済」にする
