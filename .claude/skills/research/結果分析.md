# 結果分析モード: 自分の投稿の反応を見て次の改善点を出す

プロジェクトの`投稿記録.md`を使う。

1. `投稿記録.md`から、分析していない投稿を集める
2. 投稿ごとに2つの差を見る:
   - **Claudeの案 → りゅーじ君が実際に投稿した文**: どこをどう直したか。直し方にパターンがあれば、それがりゅーじ君の基準
   - **反応(いいね・表示回数など)**: 良かった投稿と悪かった投稿で、型・テーマ・切り口・1行目・長さなど何が違うか
3. 「なんとなく良い」は禁止。違いは具体的に書く
4. 次の投稿で試すことを1〜3個に絞る
5. 分析した投稿には`投稿記録.md`に「分析済み」と印をつける

投稿数が少ないうち(10本未満)は、反応の差は偶然の可能性が高い。数字よりも「りゅーじ君の直し方」の分析を優先し、数字の話は「傾向」として控えめに書く。
