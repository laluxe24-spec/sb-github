# TikTok構成・撮影分析

1本のTikTok動画を実際にダウンロードして映像を見た上で、「構成」「撮影」「ナレーション」の3つの観点でどう作られているかを分析するスキル。りゅーじ君自身が動画を作る時に、どう撮る・どう繋ぐ・何を喋るかの参考にするのが目的。

## 手順

1. **動画をダウンロードする**(音声だけでなく映像そのものが必要):
   ```bash
   yt-dlp -o "video.%(ext)s" "<動画URL>"
   ```
   保存先はスクラッチディレクトリ(一時作業場所)。`02_Sources/03_TikTok/data/`には保存しない(このスキルの成果物は動画ファイルではなく分析結果のテキストなので、本番データに動画を残す必要はない)。

2. **カット割り(編集テンポ)を検出する**:
   ```bash
   ffmpeg -i video.mp4 -filter:v "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep showinfo | grep -oE "pts_time:[0-9.]+"
   ```
   検出したタイムスタンプの数と間隔から、動画全体の長さに対して何回カットが入ってるか(テンポの速さ)を把握する。

3. **代表的なコマを抜き出して見る**: 冒頭・検出したカットの前後・ラストなど、10〜20枚程度を`ffmpeg -ss <秒> -i video.mp4 -frames:v 1 <出力.jpg>`で抜き出し、Readツールで実際に画像を見る(この時点ではスクラッチディレクトリに置くだけでよい)。

4. **ナレーション(語り)の中身を確認する**: `02_Sources/03_TikTok/data/@<アカウント名>/transcripts/<video_id>.md`が既にあればそれを読む(tiktok-transcribeスキルで既に処理済みの場合)。無ければ`transcribe.py`で先に文字起こしを作ってから読む。

5. **3観点でまとめる**:
   - **構成**: フック(冒頭でどう惹きつけてるか)→展開(本編の見せ方)→オチ・CTA(締め方)の3パートに分け、それぞれの長さの目安と、手順2で調べたカット頻度(平均何秒に1回)を添える。
   - **撮影**: 構図(正面固定/俯瞰など)、画角の使い分け、カメラワーク(パン・手ブレを意図的に使ってるか)、背景・美術(色使い・部屋のスタイリング)、小物の見せ方を、コマ抜き画像から読み取って具体的に書く。
   - **ナレーション**: 文字起こしの中身を読み、「どういう順番で何を話してるか」という構成(例: 感想→きっかけ→準備物→手順実況→仕上がりまとめ→応用提案→CTA)と、「どういう言い回しの型を使ってるか」(接続詞の使い方、丁寧語の有無、文末表現など)をパターンとして抜き出す。**文字起こしの全文やまとまった文章をそのまま長く引用しない**。あくまで型・パターンの説明に留め、具体例が要る時も短いフレーズ止まりにする(著作物の丸写しを避けるため)。

6. **後片付け**: ダウンロードした動画ファイル自体と、使わなかったコマ抜き画像はスクラッチディレクトリのものなので、明示的に削除する必要はない(セッション終了時に自然に片付く場所に置く)。動画ファイルそのものは`02_Sources`配下には残さない。**ただし手順7で選ぶ3枚だけは`02_Sources`側に残す。**

7. **アングル参考画像を3枚選んで保存する**: 手順3で抜き出したコマの中から、**画角・アングルのパターンが異なるもの**を3枚選ぶ(同じアングルを複数選ばない)。典型的には「完成品を正面から見せる固定ショット」「手元作業の俯瞰(トップダウン)ショット」「パン・動きのあるショット」のように、撮り方の種類が分かれるものを選ぶ。`02_Sources/03_TikTok/data/@<アカウント名>/frames/`に`01_<内容>.jpg`のような連番+内容が分かるファイル名で保存する(既存アカウントで前回分析済みの場合は、その続きの連番にする)。

## 出力の見せ方・保存先

3観点(構成/撮影/ナレーション)を見出しで分けて、表や箇条書きで簡潔にまとめてりゅーじ君に提示する。OKが出たらナレッジ側と、手順7の参考画像を保存する(リソース側の文字での履歴ファイルは作らない、画像だけ残す)。

- **保存先(ナレッジ)**: `乾式.md`・`はやと式.md`と同じ「情報源(発信者)ごとの専用ファイル」形式にする。`03_Knowledge/<該当ジャンル>/<発信者名>式.md`(例: `@ichiroomvlog`名義が「ICHi」なら`03_Knowledge/06_Interior/ICHi式.md`)に、動画ごとの見出しを立てて3観点の分析を追記する(新しい分析ほど上、出典の動画URLを`【リソース】`で明記)。発信者名は概要欄・プロフィールでの名乗りを優先する(アカウントのハンドル名そのままではなく)。ジャンルが今までに無い場合は、既存の`03_Knowledge`のジャンルフォルダ構成に合わせて置き場所をりゅーじ君に確認する。
- **撮影のコツを添える**: 「撮影」観点の各ポイントには、再現に必要な具体的な数値・動作(角度の目安、距離感、機材の代わりになるもの)まで書き、該当する参考画像のファイル名を`→ 参考画像: <ファイル名>`の形で添える。

ナレーション観点をまとめる時は、文字起こしの全文やまとまった文章をそのまま長く引用しない(手順5参照、著作物の丸写しを避ける)。
