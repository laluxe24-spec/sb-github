# TikTok文字起こし

TikTok動画を`02_Sources/03_TikTok/scripts/transcribe.py`で文字起こしし、`02_Sources/03_TikTok/data/@<アカウント名>/`に保存するスキル。新しいアカウントを追加する時も、既存アカウントの動画を追加する時も同じ手順を使う。

このスキルがやるのは「何を言っているか」を文字起こしすることまで。実際にKnowledge化する判断(何が使えるノウハウか)は、無人実行(`knowledge-agent-daily`)か秘書エージェント自身が別途行う。

## 手順

1. **URLを確認する**: 個別動画URL(`https://www.tiktok.com/@アカウント名/video/数字`)を受け取る。プロフィールURLしか無い場合は、対象の動画を1本ずつ確認してから進める(まとめて全部を自動処理しない、一つずつ確認する方針)。

2. **実行する**:
   - 1本だけの場合:
     ```bash
     cd /Users/ryuji/sb-mac/02_Sources/03_TikTok
     python3 scripts/transcribe.py "https://www.tiktok.com/@アカウント名/video/数字"
     ```
   - 数十〜数百本まとめての場合、URLを1行1つのテキストファイルにしてから:
     ```bash
     python3 scripts/transcribe.py --file urls.txt
     ```

3. **完了確認**: `data/@アカウント名/transcripts/<video_id>.md`(文字起こし、フロントマターにurl・投稿者・タイトル・投稿日を含む)と`manifest.json`(動画一覧)が生成されたことを確認する。音声ファイルは文字起こし完了後に自動削除されるので気にしなくていい。
   - **既に処理済みの動画を指定された場合**: `transcribe.py`は動画IDベースで処理済みかどうかを自動判定し、「スキップ(処理済み)」と出力して正常終了する。これはエラーではなく想定通りの動作。既存の文字起こしファイルをそのまま使えばよく、削除して強制的に再実行する必要はない。

4. **新規アカウントの場合の後始末**: `data/@アカウント名/`フォルダができた時点で、翌日以降の自動収集(`auto_check.py`)から自動的にこのアカウントも対象に含まれるようになる。launchd側の設定変更は不要(新しいplistを作ったりしない)。

5. **中身の確認**: 文字起こしの中身をりゅーじ君と一緒に確認する。要約や解釈は加えず、話してる内容をそのまま事実として書き下ろすのがこのスキルの役割。OKが出れば、Knowledge化(`03_Knowledge`への保存)は無人実行(`knowledge-agent-daily`)に任せてよい。急ぎで今すぐKnowledge化したい場合だけ、秘書エージェントとして直接その場で判断・保存する。

## 注意点(過去にハマったこと)

- TikTokの動画URLに直接ブラウザでナビゲートするとエラーになりやすい(自動アクセスとみなされる)。ブラウザ操作は使わず、必ずこのスクリプト(yt-dlp経由)を使う。
- 初回実行時、Whisperモデル(数百MB〜1GB)のダウンロードで少し時間がかかる。
- 大量処理は自動でメモリ管理される(空きメモリ800MB未満で待機、10本ごとにプロセス再起動)ので、そのまま待てばよい。大量処理の前に、Chromeのタブ整理やClaudeデスクトップアプリを閉じておくと安定しやすい。
- `02_Sources`配下には知識フォルダを作らない。知識は`03_Knowledge`側にまとめる。
