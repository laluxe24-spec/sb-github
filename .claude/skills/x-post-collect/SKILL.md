# X投稿収集(投稿型)

対象アカウントの自分の投稿(本文)を、そのままプロフィールの投稿タブから取得して`02_Sources/02_X/data/@<アカウント名>/posts.json`に保存するスキル。スクショ型と違い、1件ずつの厳選は不要(自動リポストのみ除外して、あとは全件そのまま保存する)。

詳しいフォルダ構成や共通事項は`02_Sources/02_X/docs/操作メモ.md`・`docs/README.md`も参照。

## 手順

### 新しいアカウントを追加する場合
```bash
cd 02_Sources/02_X/scripts
node collect_posts.js <アカウント名>
```
- アカウント名は`@`なしで渡す(例: `mai_x0x0_21`)
- 第2引数(何ヶ月前まで遡るか)を省略するとデフォルト24ヶ月分を遡ってくれる(初回の全件取得はこれでよい)
- `data/@<アカウント名>/posts.json`が自動で新規作成される
- 実行後、`docs/README.md`の「現在の対象アカウント」の投稿型一覧に新しいアカウント名を追記する

### 既存アカウントの新着だけ取得する場合
```bash
node collect_posts.js <アカウント名> 1
```
第2引数に`1`(1ヶ月分)を渡すと、既存の`posts.json`とID重複で突き合わせて、既知の投稿にぶつかった時点で早期終了する(数秒〜数十秒で終わる軽い処理)。

### 全アカウントまとめて新着チェック
```bash
node auto_check.js
```
`data/`配下の`@kw1ew`以外の全アカウントに対して、上記の「新着だけ取得」を自動でループする(1アカウントずつ`collect_posts.js <handle> 1`を呼ぶだけ)。これは毎日launchdでも自動実行されている処理と同じなので、通常は手動で急いで叩く必要はない(「今すぐ最新を見たい」と言われた時だけ使う)。

## 注意点

- ログインセッション(`auth.json`)が切れている場合は`node login.js`でユーザー本人がXにログインする(x-screenshot-collectスキルと共通のセッションを使う)。
- 厳選は不要なので、取得できたものはそのまま保存してよい(逐一確認を取らずに自動で進めてよい)。
- 分析(文字起こし・パターンまとめなど)はこのフォルダには置かず、`03_Knowledge/03_Romance/`側に直接まとめる運用。
