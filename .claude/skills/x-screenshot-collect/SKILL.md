# Xスクショ収集(厳選型)

X上の実際の会話スクリーンショットを取得し、その中から「口説き・ラポール構築のテクニック例」として使えるものだけを人の目(Claudeの判断)で1枚ずつ選び抜いて`02_Sources/02_X/data/@<アカウント名>/スクショ/`に保存するスキル。全件をそのまま保存する`x-post-collect`とは違い、**厳選(絞り込み)が核心**。

**詳しい判断基準(残す/除外の具体例、過去の判断で迷った事例)は必ず`02_Sources/02_X/docs/操作メモ.md`を読んでから進める。**ここでは全体の流れだけをまとめる。

## 手順の概要

1. **事前準備**(初回のみ、または`node_modules`が消えている場合): `02_Sources/02_X/scripts/`で`npm install && npx playwright install chromium`
2. **ログイン確認**: `auth.json`のセッションが切れていたら`node login.js`(ユーザー本人がその場でXにログイン)
3. **新着取得**:
   ```bash
   cd 02_Sources/02_X/scripts
   node collect_media.js 30
   ```
   **第1引数は件数のみ**(アカウント名は渡さない、`USERNAME`はスクリプト内に`kw1ew`固定でハードコードされている)。`processed_ids.json`により取得済みツイートは自動スキップされる。`scripts/screenshots_batchN/`に生データが保存される。
4. **厳選**: `screenshots_batchN/`の画像を1枚ずつ確認し、操作メモ.mdの「残す/除外」基準で判定する。判断に迷ったら「実際の口説き会話のテクニック例になっているか」を基準にし、際どい判定は除外側に倒してよい。
5. **統合**: 「残す」と判定した画像を`data/@<アカウント名>/スクショ/`へ、既存の最大連番の続きから番号を振ってコピーし、`manifest.json`に`{file, tweet_url}`を追記する。
6. **後片付け**: `screenshots_batchN/`の生データを削除する。
7. **記録**: 操作メモ.mdの「<アカウント名>の現在の状態」セクションに、取得数・採用数・除外数と採用ファイル名を追記して更新する。

## 注意点

- 逐一確認を取らずに自動で進めてよい(取得・厳選・統合・生データ削除まで一通り)。
- 対象は現状`kw1ew`のみ。他のスクショ型アカウントを増やす場合は`collect_media.js`のUSERNAME部分の対応が別途必要(このスキルの対象外、まず秘書エージェントに相談する)。
