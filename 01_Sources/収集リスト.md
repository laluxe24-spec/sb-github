# 収集リスト

**いつも追いかけている情報源**と、**気になっているけどまだ追いかけていない情報源**の一覧。

- Kindleの本や、単発で見たYouTube動画のように「1回集めたら終わり」のものは、ここに入れない(頼まれた時だけ集めて、頼まれた時だけ知識にする)
- 集める時は使い道(副業用か、りゅーじ君の成長用か)を決めない。使う側(research-ai・mentor-ai)が1件ずつ決める
- 「役割」: **参考**=伸びていて参考にする人 / **比較用**=同じジャンル・同じ形なのに伸びていない人 / **お手本**=りゅーじ君が学びたい人 / **保留**=集めたデータは残すが、今は使わない
- 「気になっている人」には、りゅーじ君が見つけた人も、research-aiがバズ投稿探しで見つけた人も書く。りゅーじ君がOKした人だけ「追いかけている人」に移す(移したら`data/`に集める)
