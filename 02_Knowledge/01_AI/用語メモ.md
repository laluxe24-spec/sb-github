# 用語メモ

作業中に出てきた「これ何?」をジャンルごとに貯めておくメモ。
新しい用語が出てきたら、当てはまるジャンルが無ければその時にジャンルを追加していく。
※このファイルはClaudeが自動で読み込むものではなく、必要な時に自分で見るための辞書。

## ショートカットに関する言葉

### alias(エイリアス)
長いコマンドに、短い名前(あだ名)をつける仕組みだよ。

**イメージ**: 連絡先に「お母さん」って登録しておけば、いちいち電話番号を打たなくても「お母さん」をタップするだけでかけられるよね。それと同じで、長くて覚えにくいコマンドに短い呼び名をつけておく機能。

- 例: `resume`という短い言葉を打つだけで、実際には`claude --resume`という長いコマンドが実行される(過去のセッション一覧から選べる)
- `~/.zshrc`というファイルに登録されている
- 今使えるaliasの一覧は、ターミナルで`alias`とだけ打つと確認できる

### `.zshrc`(ズィーエスエイチアールシー)
ターミナルを開いた時に自動で読み込まれる、設定ファイルだよ。

**イメージ**: 家に帰ったら自動で電気がつく設定をしておくようなもの。ターミナルを開くたびに、ここに書かれた設定(aliasなど)が自動で有効になる。

- ホームフォルダ(`/Users/ryuji`)直下にある隠しファイル
- `resume`のようなaliasは、ここに登録することで毎回使えるようになる

### 隠しファイル・隠しフォルダ
名前が`.`(ピリオド)から始まる、普段は表示されないファイル・フォルダのことだよ。

**イメージ**: 引き出しの奥にしまってある、普段使わない書類みたいなもの。無いわけじゃなくて、ただ普段は目に入らないようにしてあるだけ。

- 例: `.claude`、`.obsidian`、`.git`、`.zshrc`
- Finderで`Cmd + Shift + .`(ピリオド)を押すと表示/非表示を切り替えられる
- 特定のフォルダに直接ジャンプしたい時は`Cmd + Shift + G`でパスを入力すればいい(隠しフォルダかどうかは関係なく開ける)

## AIの記憶・設定に関する言葉

### セッションファイルの保存場所(`~/.claude/projects/`)
ローカルで開いたClaude Codeの会話は、プロジェクトごとに1ファイル(`.jsonl`)としてまるごと保存されてる。保存先はここ。

```
/Users/ryuji/.claude/projects/
```

**イメージ**: プロジェクトごとの引き出しがあって、その中に会話1つにつき1枚の紙(ファイル)が入ってるようなもの。

- フォルダ名はプロジェクトのパスをそのまま繋げたもの(例: `sb-mac`プロジェクトなら`-Users-ryuji-sb-mac`フォルダ)
- ファイル名はUUID形式のセッションID(下の「セッションID」の項目参照)、更新日時が新しいものほど最近の会話
- ここから直接ファイルをゴミ箱に入れれば、そのセッションの履歴を手動で削除できる
- ただし今使ってる会話自身のファイルを消すと、その会話がそれ以降保存できなくなる可能性がある点は注意

### ターミナル と シェル の違い
「ターミナル」は、コマンドを打つための「箱(アプリ)」そのもの(例: Terminal.app)。「シェル」は、その箱の中で実際に動いていて、打った文字を理解して実行してくれる「中身のプログラム」(例: zsh)。

**イメージ**: テレビ(ターミナル)と、その中の受信機(シェル)の関係。「テレビに映る」と言っても実際に処理してるのは中の受信機だけど、普段は「テレビに映す」って言うのと同じで、「ターミナルに打つ」と「シェルに打つ」は実質同じ動作を指してると思っていい。

### プロンプト(2つの意味がある、紛らわしい言葉)
「プロンプト」には、場面によって全く違う2つの意味があるよ。

**イメージ**: 「お会計」という言葉が、レジでの「支払い」を指す時と、飲み会の「会計係」を指す時があるのと同じで、同じ単語でも場面で意味が変わる。

- **①シェルのプロンプト**: Claudeを起動する**前**の、ターミナルの「入力待ちマーク」のこと(`ryuji@MacBook-Air-2 ~ %`のような表示)。「さあコマンドをどうぞ」という合図でしかない。
- **②AIのプロンプト**: Claudeが起動した**後**、りゅーじ君がClaudeに向かって打つ**メッセージ・指示そのもの**のこと。「プロンプトを入力する」と言ったら、普通こっちを指す。

「シェル」に打つコマンド(`claude remote-control`など)と、「プロンプト(②の意味)」として打つメッセージ(`/remote-control`など)は、打つ場所も意味も違う、という点に注意。

### config(コンフィグ)/ `/config`
「config」は英語の「configuration(設定)」の略で、「設定」という意味だよ。

**イメージ**: レストランで注文をカスタマイズする時の「辛さ:普通/辛口」「たれ:多め/少なめ」みたいな選択メニューのこと。Claude Codeにも、動作を自分好みに調整できる項目がいろいろあって、それをまとめて呼ぶ時に「config」と言う。

- Claude Codeの会話中に`/config`と打つと、その設定メニューの画面が開く
- 例: 「起動するたび自動でリモート接続するか」(`remoteControlAtStartup`)などを、この画面からオン/オフできる
- 設定の中身は、実際には`~/.claude/settings.json`というファイルに保存されている。`/config`はそのファイルを直接編集しなくても、画面上のメニュー操作で同じことができる、という位置づけ

### セッションID(2種類ある)
Claude Codeの「セッションID」には、実は用途が違う2種類があるよ。

**イメージ**: 宅配便の「伝票番号」と、倉庫の中の「棚番号」の違いみたいなもの。同じ荷物でも、外部向けの番号と、倉庫内だけで通じる番号は別物。片方をもう片方の代わりに使おうとしても、通じない。

- **Web/属性用ID**(`session_01...`という形式): コミットメッセージやPRの署名に使われる、claude.ai側のセッション識別子
- **ローカル再開用ID**(ハイフン区切りのUUID形式、例: `236a9e03-cace-4979-...`): `claude --resume <ID>`で実際にパソコン上のセッションを再開する時に使う番号。`~/.claude/projects/<プロジェクトのパス名>/`フォルダの中のファイル名がこれにあたる
- Web用IDを`--resume`に渡してもローカルには見つからず、エラーになる
- 「これが今のセッションのIDか」を確認したい時は、更新日時が今の時刻に近いファイルを`~/.claude/projects/`配下で探すと見つかる

### Claudeのメモリ(記憶機能)
Claude(俺)が、りゅーじ君とのやり取りの中で学んだ「今後もずっと守るべきルール」を、自分で保存しておく機能だよ。パソコンの性能を表す「メモリ(RAM)」とは全くの別物。

**イメージ**: 秘書が「この人はいつもこう呼んでほしいんだったな」とメモ帳に書き留めておいて、次に会う時もそれを見て思い出す、みたいなもの。

- 場所: `/Users/ryuji/.claude/projects/-Users-ryuji/memory/`(sb-macプロジェクトの外、Claudeのアカウント自体に紐づく)
- ここに書かれたことは、sb-macに限らず、どんな会話・どんなプロジェクトでも効く
- りゅーじ君が「覚えといて」と言わなくても、Claude自身が「これは今後も大事なルールだ」と判断したら自動で保存することもある

## 画像から情報を取り出す技術

### OCR(オーシーアール)
「Optical Character Recognition(光学文字認識)」の略だよ。簡単に言うと、画像の中に写ってる文字を、コンピューターが読み取って「テキストデータ」に変換する技術のこと。

**イメージ**: 誰かに写真を見せて「これ何て書いてある?文章にして」ってお願いするようなもの。写真そのものはコピペできないけど、書き起こしてもらった文章ならコピペも検索もできるよね。それをコンピューターが自動でやってくれる。

- 例えばKindleの`screenshots/`フォルダには、本のページを撮った「画像」(png)しかない
- OCRを使うと、その画像に写ってる文章を読み取って「文字」として抜き出せる
- そうすると、コピペしたり、検索したり、要約を作ったりできるようになる

つまり「画像→文字」に変換する作業、というイメージ。

## パソコンの体力に関する言葉

### リソース
Macが作業に使える「体力・容量」のことだよ。

**イメージ**: 机の広さや、同時に抱えられる仕事の量のようなもの。

- **メモリ(RAM)**: 机の広さ。広いほど、いろんな作業を同時に広げられる
- **CPU**: 頭の回転の速さ。処理をどれだけ速くこなせるか

セッション(Claudeとの会話)を起動しっぱなしにするのは、「机の上に道具を広げっぱなしにしておく」ようなもの。増えるほど机(メモリ)が狭くなり、他の作業がしづらくなる。

## 何かを動かす(プログラムを実行する)時に使う環境

### Python(パイソン)
プログラムを書くための言語の1つだよ。

**イメージ**: 料理のレシピみたいなもの。「①玉ねぎを切る ②炒める ③味付けする」って手順を紙に書いておけば、誰か(この場合はコンピューター)がその通りに再現してくれる。Pythonは、そのレシピを書くための言葉の1つ。

- 人間が読み書きできる言葉でプログラムを書く
- それをコンピューターが実行することで、自動で作業をしてくれる
- Kindleのスクショを撮るスクリプト(`kindle_screenshot.py`)は、このPythonで作られている

### venv(ブイイーエヌブイ)
Pythonを動かすための、専用の作業スペースのようなものだよ。

**イメージ**: キッチンの調味料セットを、和食用・洋食用で別々の箱に分けておくようなもの。全部同じ棚にごちゃ混ぜにすると、間違えて醤油とオリーブオイルが混ざったりして料理(プログラム)が失敗しやすくなる。venvは、プロジェクトごとに専用の道具箱を用意して、混ざらないようにする仕組み。

- プロジェクトごとに、必要な道具(ライブラリ)を分けて用意できる
- 別プロジェクトの道具と混ざらないので、壊れにくい

### JavaScript / Node.js
これもPythonと同じ、プログラムを書くための言語の1つ。

**イメージ**: 同じ「カレーの作り方」でも、日本語レシピと英語レシピがあるようなもの。できあがる料理(結果)は似ていても、書き方(言語)が違う。

- X解析のスクリプト(`collect_media.js`など)はこちらで作られている
- 同じ「プログラムを動かす」でも、Kindleと X解析では使ってる言語が違う、というだけ

## 何かを保存・記録する時に使うもの

### Git(ギット)
ファイルの変更履歴を記録・管理する仕組みだよ。

**イメージ**: ゲームの「セーブポイント」だと思うとわかりやすい。ゲームで強いボスの前にセーブしておけば、負けても「セーブした場所」からやり直せるよね。Gitも同じで、作業のキリがいいところで「ここまでOK」ってセーブしておくと、後で失敗しても「あの時の状態」に戻れる。

- ファイルを変更する
- 「ここまでの変更を保存」って記録する(これを**コミット**と呼ぶ = セーブする、と同じ)
- 後から「いつ・何が変わったか」を確認したり、必要なら前の状態に戻したりできる

### GitHub(ギットハブ)
Gitで管理してるプロジェクトを、インターネット上に保存・共有できるサービスだよ。

**イメージ**: ゲームのセーブデータをクラウドに預けておく機能のようなもの。自分のパソコンが壊れても、クラウドにセーブデータがあれば安心。しかも、そのセーブデータを友達(他の人やAI)と共有して、一緒に遊ぶ(作業する)こともできる。

- 手元のパソコンだけじゃなく、外のサーバーにもバックアップされる
- 他の人やAI(Claude)と同じファイルを共有できる

### リポジトリ
1つのプロジェクトの、Gitで管理されているファイル一式のことだよ。

**イメージ**: セーブデータが全部まとまって入ってる「保管庫」そのもの。`sb-mac`フォルダ全体が1つのリポジトリ、というイメージ。

### コミット
「ここまでの変更を記録として保存する」操作だよ。

**イメージ**: ゲームで「セーブする」のボタンを押す、その動作そのもの。変更の節目ごとに行う、セーブポイント作成のこと。

### プッシュ
手元(ローカル)で作ったコミットを、GitHub(リモート)側へ送って反映させることだよ。

**イメージ**: 手元のスマホで撮った写真を、クラウドアルバムに「アップロード」するボタンを押すイメージ。手元にあるだけじゃまだクラウドには残ってない。

- コミット = 手元でセーブ
- プッシュ = そのセーブをインターネット上にも送る

## ファイルの場所を表す言葉

### パス(path)
ファイルやフォルダの「住所」のことだよ。

**イメージ**: 郵便物の宛先と同じ。「東京都→○○区→○○丁目→○○番地」って辿っていくのと同じように、「sb-macフォルダ→01_Sourcesフォルダ→…」と辿っていく道順がパス。

- そのファイルがコンピューターのどこにあるかを、フォルダをたどる道順で表した文字列
- 例: `01_Sources/02_X/data/@kw1ew/スクショ/001.jpg`(01_Sourcesフォルダ→02_Xフォルダ→…とたどっていく道順そのもの)
- フォルダを移動すると、そのファイルの「住所」も変わるので、操作メモなどに書いてあるパスの記述も合わせて書き直す必要がある

## ファイルの種類

### .md(マークダウン)
見出しや箇条書きが書ける、シンプルなテキストファイル形式だよ。

**イメージ**: 普通のメモ帳に、太字や見出し、箇条書きみたいな「ちょっとした飾り付け」ができるようになったバージョン。難しい専用ソフトがなくても、記号を書くだけで見やすい文書が作れる。

- `# 見出し`と書くと見出しになる
- `- 箇条書き`と書くと箇条書きになる
- このプロジェクトの操作メモやREADMEは全部この形式で書かれている

### .py
Pythonのプログラムが書かれたファイルだよ。

**イメージ**: 「Python語」で書かれたレシピそのものが入ったファイル。

### .js
JavaScriptのプログラムが書かれたファイルだよ。

**イメージ**: 「JavaScript語」で書かれたレシピそのものが入ったファイル。
