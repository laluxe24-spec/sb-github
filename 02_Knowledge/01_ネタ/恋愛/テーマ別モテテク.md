# テーマ「LINE」の分かれ道

- データ: `LINE.tsv`(437行・7アカウント: Sta_Lo / romant / bagura / rei072 / Todai_ / mai_x0 / mirei_)
- sideの判定は機械的なので、中身を読み直して⭕/❌を振り分け直した(例: 「既読スルーされたら追撃する」は機械判定ではモテ側だが、中身は非モテ行動なので❌に入れた)
- 対象外として外したもの: 夜の話・体の話(「ボディライン」など)・中身のない断片(「LINEで、」「LINEは」など)
- 裏付けの見方: **行数 / 件数合計 / 何人(7人中) / 最大表示回数**
- 女性の反応: 「」はデータにある言葉。[作] はデータに無いので自然な形で作ったもの

## 1. 返信の速さ ⚠️意見が割れている
**裏付け: 78行 / 85件 / 7人 / 最大 4,934,362回**

- **場面**: 彼女からLINEが来た。すぐ返す? それとも少し置く?

- ❌ **非モテ**: 既読がついた瞬間に、毎回1分以内で返す
  - セリフ例: 「既読からの返信が、毎回1分以内」
- **女性の反応**
  - ⭕側: 「返信や会う頻度を押し付けないと『私のこと尊重してくれてる』って思う」
  - ❌側: 「返信が早すぎると、“ずっと暇なの？”って無意識で格下に感じる」
- ⚠️ **割れている点**: 最多数(即レス=非モテ)に対して、反対の意見も少なくない。

## 3. わざと遅らせる・わざと既読スルーする(駆け引き) ⚠️意見が割れている
**裏付け: 35行 / 45件 / 7人 / 最大 1,060,456回**

- **場面**: 「追わせたい」から、返信の間隔をわざと空けるか迷う
- ⭕ **モテ**: 作戦で遅らせない。返信は自分の生活の都合でばらつく(自然体のムラ)
  - セリフ例: 「返信を遅らせず自分の生活を優先する」「元から返信にムラがある（自然体）」
- ❌ **非モテ**: 駆け引きで既読を遅らせる・盛り上がっているのに急に止める
  - セリフ例: 「わざと既読無視して駆け引きする」「返信を遅らせればモテると思ってる」
- **女性の反応**
  - ⭕側: 「返信が来るか気になる」
  - ❌側: 「急に返信を遅らせる → わざとらしい」
- ⚠️ **割れている点**: 多数派は「わざと=バレて逆効果」(romant 4件、rei072、Todai_、mai_x0)。一方で「あえて既読スルーを使う」(rei072)、「既読スルーもたまにする」「LINEの返信はいつも気まぐれ」(Sta_Lo)、「たまに返信を遅らせる」「即レスをやめて夜にまとめて返信」(romant)、「返信頻度を一定にしない」(bagura)など、**「たまに間を空けるのは有効」派も同じアカウント内にいる**。違いは「作戦としてやる(❌)」か「生活の結果そうなる(⭕)」か

## 1. 沈黙になった時

## 2. 何を話すか(話題選び)

- 裏付け: 101行 / 129件 / 7人 / 最大 1,573,583
- ⚠️意見が割れている:
