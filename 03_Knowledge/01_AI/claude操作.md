# Claude操作メモ

Claude Codeを複数の画面(ターミナル、VS Code、デスクトップアプリなど)から使う時に迷った点をまとめたメモ。

## 合言葉(ショートカット)

この2つの言葉を言うだけで、Claudeが説明なしでコマンドだけコピペ用に出してくれる。

### 「リモート」と言うと
VS Codeなど**別の画面で、今の会話を吹き出し付きの見た目のまま**開くためのコマンドが出る。

**イメージ**: テレビ番組をスマホでも同時に見れるようにする「同時配信」のスイッチ。

```
/remote-control
```
これを、開いた**別画面側のターミナル**に貼り付けて使う。

### 「ターミナル再開」と言うと
今の会話を、**ターミナル上で文字だけ**で呼び出す(続きから話せる)ためのコマンドが出る。

**イメージ**: チャットのログを印刷して、続きから読むようなもの。見た目は装飾なしの文字だけ。

```
claude --resume <その時のセッションID>
```
セッションIDは会話ごとに変わるので、毎回その時の正しい番号で出てくる。

## 同じ会話を別の画面から見たい/続けたい

### `claude --resume`
過去の会話(セッション)を、ターミナル上で「文字だけ」で再開するコマンド。

**イメージ**: チャットの「ログだけ」を印刷してもう一度読むようなもの。会話の続きはできるけど、吹き出しの見た目や装飾は無く、テキストがそのまま流れるだけ。

- `claude --resume` だけ打つと、過去のセッション一覧が出てくる
- `claude --resume <セッションID>` のようにIDを直接指定すると、そのセッションだけを呼び出せる
- **注意**: セッション一覧は「今いるフォルダ」ごとに変わる。`sb-mac`フォルダの中で打つと`sb-mac`で始めた会話しか出てこない。1つ上の「ホームフォルダ」(`/Users/ryuji`)で始めた会話を呼びたい時は、セッションIDを直接指定するのが確実

### セッションID
それぞれの会話につけられた固有の番号(例: `ba635277-6970-44d4-b7bd-21123fc7122a`)。

**イメージ**: 会話ごとの「整理番号」。この番号さえ分かれば、どのフォルダにいても、その会話をピンポイントで呼び出せる。

### Remote Control(リモートコントロール)
動いてる会話(セッション)を、別の画面(VS Code、スマホ、ブラウザなど)からも見たり操作したりできるようにする機能。

**イメージ**: テレビ番組を、テレビだけじゃなくスマホでも同時に見れるようにする「同時配信」のようなもの。`claude --resume`が「録画を後で見る」だとしたら、Remote Controlは「今起きてることをリアルタイムで別画面にも映す」イメージ。

- ターミナルで`/remote-control`と打つと有効になる(会話中にリンクやコードが表示されるはず)
- 有効にすると、VS Codeの「Claude Code」拡張パネル側からも、**吹き出し付きのちゃんとした見た目**でこの会話に繋がれる
- 条件: Claude.aiアカウントでのサインインが必要(APIキーだけの利用では使えない)

### リモートが切れても、会話自体は消えてない
Remote Controlの接続が切れても、セッション(会話の中身・作業状態)自体は無事に残ってる。切れるのは「今の画面からそのセッションに話しかける経路」だけ。

**イメージ**: テレビ番組の同時配信が途切れても、番組自体(放送)は続いてるのと同じ。リモコンの電池が切れただけで、テレビが壊れたわけじゃない。

- 焦って何かを作り直す必要はない
- もう一度`/remote-control`を入れれば、同じセッションに再接続できる

### VS Codeでこの会話を開く、具体的な手順
「今のこの会話を、VS Code上でも吹き出し付きの見た目で見たい」時の手順。1つずつ、次に進む前に「画面に何が出たか」を確認しながらやる。

**1. VS Codeでターミナルを開く**
上部メニューの `表示(View)` → `ターミナル(Terminal)` を選ぶ(または `Ctrl + \`` )。
→ 画面下に `ryuji@MacBook-Air-2 ...` のような入力欄(ターミナル)が出てくればOK。

**2. このセッションを呼び出す**
そのターミナルに、次をそのまま貼り付けてEnter。
```
claude --resume ba635277-6970-44d4-b7bd-21123fc7122a
```
→ このセッションの会話ログが、文字だけでターミナルに表示されればOK(ここではまだ吹き出しは付かない、これで正常)。

**3. 吹き出し付きの見た目に切り替える**
同じターミナルの中で、続けて次を打ってEnter。
```
/remote-control
```
→ リンクやコードが表示され、しばらくするとVS Code右側などの「Claude Code」パネルに、いつも通り吹き出し付きでこの会話が表示されればOK。

**もし表示が消えても慌てなくていい**: 会話自体は残ってるので、もう一度`/remote-control`を打てば復活する(詳しくは上の「リモートが切れても、会話自体は消えてない」を参照)。

### 今いるフォルダが目的のプロジェクトと違う時
`claude --resume`や、その他の作業をする時、今いるフォルダ(例: ホームフォルダ`/Users/ryuji`)が、作業したいプロジェクトのフォルダ(例: `sb-mac`)と違うことがある。

**イメージ**: 家(ホームフォルダ)の玄関にいるのに、作業したいのは2階の子供部屋(sb-macフォルダ)、みたいな状態。

- 今どのフォルダにいるかは、ターミナルのプロンプト(`ryuji@MacBook-Air-2 sb-mac %`のような表示)の後ろ側で分かる
- 目的のフォルダに移動したい時はこう打つ
  ```
  cd /Users/ryuji/sb-mac
  ```
- `cd`は「Change Directory(フォルダを変える)」の略

### まとめ表

| やりたいこと | 使うもの | 見た目 |
|---|---|---|
| ターミナルで続きから話す | `claude --resume <ID>` | 文字だけ(装飾なし) |
| VS Codeでも同じ見た目で話す | `/remote-control` | 吹き出し付き(元の見た目と同じ) |
