# 操作メモ

Claude Codeを複数の画面(ターミナル・VS Code・iPhone)から使う時、毎回使う操作のメモ。「今どんな場面か」で探せるように並べてある。セットアップの詳細(Tailscale・Termiusの初期設定)は`設備メモ.md`を参照。

## クイックリファレンス(コマンド一覧)

| やりたいこと | コマンド |
|---|---|
| ターミナルで続きから話す | `claude --resume <セッションID>` |
| 続きから話す(合言葉) | 「ターミナル再開」と言う |
| 吹き出し付きの見た目にする | `/remote-control` |
| 吹き出し付きの見た目にする(合言葉) | 「リモート」と言う |
| iPhoneで最新のナレッジを見る | GitHubアプリで`sb-github`を開く |
| 目的のフォルダに移動する | `cd /Users/ryuji/sb-mac` |
| 隠しフォルダにジャンプする(Finder) | `Cmd + Shift + G` |
| 隠しファイルの表示切替(Finder) | `Cmd + Shift + .` |

---

## シーン1: iPhoneから使う時(毎回の手順)

1. iPhoneでTermiusを開く
2. 登録済みのホストをタップして接続
3. 繋がったら、ターミナル画面で以下を打つだけでこのセッションに戻れる
   ```
   resume
   ```
4. リッチな見た目(吹き出し付き)でVS Codeなどから見たい場合は、続けて以下を打つ
   ```
   /remote-control
   ```

**注意**: Macがスリープしてると外出先から繋がらない。パスワードやSSHの鍵情報は、Claudeとのチャットには絶対に貼らない(Termiusアプリの入力欄に直接入力する)。

## シーン2: VS Codeでこの会話を開きたい時(具体的な手順)

1. **VS Codeでターミナルを開く** — 上部メニューの`表示(View)`→`ターミナル(Terminal)`(または`Ctrl+\``)
2. **このセッションを呼び出す** — 以下を貼り付けてEnter(文字だけの会話ログが出ればOK、まだ吹き出しは付かない)
   ```
   claude --resume <セッションID>
   ```
3. **吹き出し付きの見た目に切り替える** — 続けて以下を打つ(リンクやコードが表示され、VS Code右側の「Claude Code」パネルに吹き出し付きで表示されればOK)
   ```
   /remote-control
   ```

## シーン3: iPhoneでKnowledge(ナレッジ)を読みたい時(毎回の操作)

GitHubアプリで`sb-github`リポジトリを開き、「コード」をタップしてフォルダを辿る(`03_Knowledge`など)。中身はMac側とリアルタイムで同じなので、Pullのような操作は不要。

## シーン4: 今いるフォルダが目的のプロジェクトと違う時

`claude --resume`や他の作業をする時、今いるフォルダ(例: ホームフォルダ`/Users/ryuji`)が、作業したいプロジェクトのフォルダ(例: `sb-mac`)と違うことがある。

**イメージ**: 家(ホームフォルダ)の玄関にいるのに、作業したいのは2階の子供部屋(sb-macフォルダ)、みたいな状態。

- 今どのフォルダにいるかは、ターミナルのプロンプト(`ryuji@MacBook-Air-2 sb-mac %`のような表示)の後ろ側で分かる
- 目的のフォルダに移動したい時:
  ```
  cd /Users/ryuji/sb-mac
  ```
  (`cd`は「Change Directory」の略)

## シーン5: Finderで深い場所・隠しフォルダを開きたい時

**`Cmd + Shift + G`**(「フォルダへ移動」): Finderを開いた状態でこのキーを押すと、パスを直接入力してそのフォルダにジャンプできるダイアログが出る。`.claude`のような隠しフォルダでも、パスさえ分かればこれで一発で開ける(隠しフォルダの表示設定をオンにする必要すらない)。

例:
```
/Users/ryuji/.claude/projects/-Users-ryuji/memory/
```
と貼り付けてEnter。

**`Cmd + Shift + .`**(ピリオド): 今開いてるFinderのウィンドウ全体で、隠しファイル・隠しフォルダ(名前が`.`で始まるもの、例: `.claude`、`.obsidian`、`.git`)の表示/非表示を切り替える。もう一度押すと元に戻る。

## 補足: コマンド・用語の詳しい説明

### 合言葉(ショートカット)とは

この2つの言葉を言うだけで、Claudeが説明なしでコマンドだけコピペ用に出してくれる。

- **「リモート」と言うと** → `/remote-control`(VS Codeなど別画面で、吹き出し付きの見た目のまま今の会話を開く)
- **「ターミナル再開」と言うと** → `claude --resume <その時のセッションID>`(ターミナル上で文字だけの続きから話す)

**注意**: これは「言うとコマンドを出してくれる」だけで、その後コピペして打つ必要がある。一方、`resume`は`.zshrc`に登録された**alias(ショートカットコマンド)**そのもので、打った瞬間に即実行される。似てるけど別物。

### `claude --resume`とは

過去の会話(セッション)を、ターミナル上で「文字だけ」で再開するコマンド。

**イメージ**: チャットの「ログだけ」を印刷してもう一度読むようなもの。会話の続きはできるけど、吹き出しの見た目や装飾は無く、テキストがそのまま流れるだけ。

- `claude --resume`だけ打つと、過去のセッション一覧が出てくる
- `claude --resume <セッションID>`のようにIDを直接指定すると、そのセッションだけを呼び出せる
- **注意**: セッション一覧は「今いるフォルダ」ごとに変わる。`sb-mac`フォルダの中で打つと`sb-mac`で始めた会話しか出てこない。1つ上の「ホームフォルダ」(`/Users/ryuji`)で始めた会話を呼びたい時は、セッションIDを直接指定するのが確実
- **セッションID**: 会話ごとの「整理番号」(例: `ba635277-6970-44d4-b7bd-21123fc7122a`)。この番号さえ分かれば、どのフォルダにいても、その会話をピンポイントで呼び出せる

### Remote Control(リモートコントロール)とは

動いてる会話(セッション)を、別の画面(VS Code、スマホ、ブラウザなど)からも見たり操作したりできるようにする機能。

**イメージ**: テレビ番組を、テレビだけじゃなくスマホでも同時に見れるようにする「同時配信」のようなもの。`claude --resume`が「録画を後で見る」だとしたら、Remote Controlは「今起きてることをリアルタイムで別画面にも映す」イメージ。

- ターミナルで`/remote-control`と打つと有効になる(会話中にリンクやコードが表示される)
- 有効にすると、VS Codeの「Claude Code」拡張パネル側からも、**吹き出し付きのちゃんとした見た目**でこの会話に繋がれる
- 条件: Claude.aiアカウントでのサインインが必要(APIキーだけの利用では使えない)

**リモートが切れても、会話自体は消えてない**: 接続が切れても、セッション(会話の中身・作業状態)自体は無事に残ってる。切れるのは「今の画面からそのセッションに話しかける経路」だけ。焦って何かを作り直す必要はなく、もう一度`/remote-control`を入れれば同じセッションに再接続できる。
