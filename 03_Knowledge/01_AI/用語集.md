# 用語集

作業中に出てきた「これ何?」をジャンルごとに貯めておくメモ。
新しい用語が出てきたら、当てはまるジャンルが無ければその時にジャンルを追加していく。
※このファイルはClaudeが自動で読み込むものではなく、必要な時に自分で見るための辞書。

## 画像から情報を取り出す技術

### OCR(オーシーアール)
「Optical Character Recognition(光学文字認識)」の略だよ。簡単に言うと、画像の中に写ってる文字を、コンピューターが読み取って「テキストデータ」に変換する技術のこと。

**イメージ**: 誰かに写真を見せて「これ何て書いてある?文章にして」ってお願いするようなもの。写真そのものはコピペできないけど、書き起こしてもらった文章ならコピペも検索もできるよね。それをコンピューターが自動でやってくれる。

- 例えばKindleの`screenshots/`フォルダには、本のページを撮った「画像」(png)しかない
- OCRを使うと、その画像に写ってる文章を読み取って「文字」として抜き出せる
- そうすると、コピペしたり、検索したり、要約を作ったりできるようになる

つまり「画像→文字」に変換する作業、というイメージ。

## 何かを動かす(プログラムを実行する)時に使う環境

### Python(パイソン)
プログラムを書くための言語の1つだよ。

**イメージ**: 料理のレシピみたいなもの。「①玉ねぎを切る ②炒める ③味付けする」って手順を紙に書いておけば、誰か(この場合はコンピューター)がその通りに再現してくれる。Pythonは、そのレシピを書くための言葉の1つ。

- 人間が読み書きできる言葉でプログラムを書く
- それをコンピューターが実行することで、自動で作業をしてくれる
- Kindleのスクショを撮るスクリプト(`kindle_screenshot.py`)は、このPythonで作られている

### venv(ブイイーエヌブイ)
Pythonを動かすための、専用の作業スペースのようなものだよ。

**イメージ**: キッチンの調味料セットを、和食用・洋食用で別々の箱に分けておくようなもの。全部同じ棚にごちゃ混ぜにすると、間違えて醤油とオリーブオイルが混ざったりして料理(プログラム)が失敗しやすくなる。venvは、プロジェクトごとに専用の道具箱を用意して、混ざらないようにする仕組み。

- プロジェクトごとに、必要な道具(ライブラリ)を分けて用意できる
- 別プロジェクトの道具と混ざらないので、壊れにくい

### JavaScript / Node.js
これもPythonと同じ、プログラムを書くための言語の1つ。

**イメージ**: 同じ「カレーの作り方」でも、日本語レシピと英語レシピがあるようなもの。できあがる料理(結果)は似ていても、書き方(言語)が違う。

- X解析のスクリプト(`collect_media.js`など)はこちらで作られている
- 同じ「プログラムを動かす」でも、Kindleと X解析では使ってる言語が違う、というだけ

## 何かを保存・記録する時に使うもの

### Git(ギット)
ファイルの変更履歴を記録・管理する仕組みだよ。

**イメージ**: ゲームの「セーブポイント」だと思うとわかりやすい。ゲームで強いボスの前にセーブしておけば、負けても「セーブした場所」からやり直せるよね。Gitも同じで、作業のキリがいいところで「ここまでOK」ってセーブしておくと、後で失敗しても「あの時の状態」に戻れる。

- ファイルを変更する
- 「ここまでの変更を保存」って記録する(これを**コミット**と呼ぶ = セーブする、と同じ)
- 後から「いつ・何が変わったか」を確認したり、必要なら前の状態に戻したりできる

### GitHub(ギットハブ)
Gitで管理してるプロジェクトを、インターネット上に保存・共有できるサービスだよ。

**イメージ**: ゲームのセーブデータをクラウドに預けておく機能のようなもの。自分のパソコンが壊れても、クラウドにセーブデータがあれば安心。しかも、そのセーブデータを友達(他の人やAI)と共有して、一緒に遊ぶ(作業する)こともできる。

- 手元のパソコンだけじゃなく、外のサーバーにもバックアップされる
- 他の人やAI(Claude)と同じファイルを共有できる

### リポジトリ
1つのプロジェクトの、Gitで管理されているファイル一式のことだよ。

**イメージ**: セーブデータが全部まとまって入ってる「保管庫」そのもの。`sb-mac`フォルダ全体が1つのリポジトリ、というイメージ。

### コミット
「ここまでの変更を記録として保存する」操作だよ。

**イメージ**: ゲームで「セーブする」のボタンを押す、その動作そのもの。変更の節目ごとに行う、セーブポイント作成のこと。

### プッシュ
手元(ローカル)で作ったコミットを、GitHub(リモート)側へ送って反映させることだよ。

**イメージ**: 手元のスマホで撮った写真を、クラウドアルバムに「アップロード」するボタンを押すイメージ。手元にあるだけじゃまだクラウドには残ってない。

- コミット = 手元でセーブ
- プッシュ = そのセーブをインターネット上にも送る

## ファイルの場所を表す言葉

### パス(path)
ファイルやフォルダの「住所」のことだよ。

**イメージ**: 郵便物の宛先と同じ。「東京都→○○区→○○丁目→○○番地」って辿っていくのと同じように、「sb-macフォルダ→02_Sourcesフォルダ→…」と辿っていく道順がパス。

- そのファイルがコンピューターのどこにあるかを、フォルダをたどる道順で表した文字列
- 例: `02_Sources/02_X/data/@kw1ew/スクショ/001.jpg`(02_Sourcesフォルダ→02_Xフォルダ→…とたどっていく道順そのもの)
- フォルダを移動すると、そのファイルの「住所」も変わるので、操作メモなどに書いてあるパスの記述も合わせて書き直す必要がある

## ファイルの種類

### .md(マークダウン)
見出しや箇条書きが書ける、シンプルなテキストファイル形式だよ。

**イメージ**: 普通のメモ帳に、太字や見出し、箇条書きみたいな「ちょっとした飾り付け」ができるようになったバージョン。難しい専用ソフトがなくても、記号を書くだけで見やすい文書が作れる。

- `# 見出し`と書くと見出しになる
- `- 箇条書き`と書くと箇条書きになる
- このプロジェクトの操作メモやREADMEは全部この形式で書かれている

### .py
Pythonのプログラムが書かれたファイルだよ。

**イメージ**: 「Python語」で書かれたレシピそのものが入ったファイル。

### .js
JavaScriptのプログラムが書かれたファイルだよ。

**イメージ**: 「JavaScript語」で書かれたレシピそのものが入ったファイル。
