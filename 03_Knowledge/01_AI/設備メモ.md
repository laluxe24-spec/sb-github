## 外出先からMacに繋ぐ仕組み(Tailscale + Termius)

**イメージ**: 自宅のMacとiPhoneの間だけに、専用の秘密のトンネルを掘るようなもの。このトンネル(Tailscale)を通って、iPhoneからMacのターミナル(SSH)に鍵を挿して入る、という2段構え。

```
iPhone(Termiusアプリ)
  → Tailscaleの専用トンネルを通る
  → Macのターミナルにログイン(SSH)
  → resume や /remote-control を実行
```

**セットアップ済みの内容**
- **Mac側: Tailscale** — インストール・ログイン済み(Googleアカウント)。MacのTailscale上のIPアドレス: `100.123.41.89`(固定、メニューバーのTailscaleアイコンから確認可)。「Start at login」ON済み(再起動しても自動起動)
- **Mac側: リモートログイン(SSH)** — 「システム設定」→「一般」→「共有」→「リモートログイン」ON済み、アクセス許可は「管理者のみ」に制限済み
- **iPhone側: Termius** — 「Termius: Modern SSH Client」インストール済み(アカウント作成不要、「Continue with Basic SSH」でスキップ)。接続先ホスト登録済み: IP `100.123.41.89` / ユーザー名 `ryuji` / パスワードはMacのログインパスワード
- 外出中も使いたいなら、Macを電源に繋ぎっぱなしにして、「システム設定」→「バッテリー」で「電源アダプタ接続時にディスプレイオフでもスリープしない」をONにしておく(または`sudo pmset -c sleep 0`)
