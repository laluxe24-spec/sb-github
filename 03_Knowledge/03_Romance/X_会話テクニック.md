# 会話テクニック

収集した7アカウント(計約2,775件)とkw1ewの会話分析(98枚/30パターン)のうち、LINE・会話・言い回し・おもしろ返しに関する部分をまとめたもの。行動・判断に関するものは `行動テクニック.md` を参照。出典アカウント名は記載せず、内容の妥当性で評価している。

根拠レベル:
- **A**: 心理学・行動科学の確立した理論や研究に対応
- **B**: 複数の情報源で独立して繰り返し主張されている経験則
- **C**: 一つの情報源のみだが、メカニズムの説明が筋が通っている経験則
- **D**: 根拠が弱い・個人差が大きい・再現性に疑問がある

## 1. LINE完全攻略

### 1-1. 基本ルール
| ルール | 根拠レベル |
|---|---|
| 返信速度は「常に即レス」より「盛り上がった時は早め、それ以外は自然なペース」の方がバランスが良いとされる | B |
| 文章量は相手と同程度〜やや短めが無難。長文連投は「必死さ」として受け取られやすい | B |
| 質問だけで構成された文(「?」で終わる文の連発)は「面接っぽい」と受け取られやすい。断定文や共感の一言を混ぜる | B |
| スタンプは自分の好みではなく相手がよく使うものに寄せる方が自然という指摘 | C |
| 既読後すぐ返信がなくても、相手の生活(仕事・移動中など)の可能性を先に考える | C |

### 1-2. 返信が遅い/来ない時
| 状況 | 判断 | 根拠レベル |
|---|---|---|
| 数時間返信がない | 「興味がない」の証拠ではなく、他の予定・気分・考える時間が理由であることが多いという指摘が複数(実際にLINE無視の心理学研究でも、相手への評価低下が理由とは限らないという知見がある) | B |
| 何日も既読無視が続く | 一度だけ、催促にならない軽い話題を送ってみるのは許容範囲。それでも反応がなければ、いったん距離を置いて様子を見る | C |

### 1-3. 相槌・話の広げ方の質
「そうなんだ」「それな」など同じ相槌を繰り返す返し方は、何を話しても同じ反応に見え、話を軽く流している印象を与えやすい、という指摘(B)。相手の発言の一部を拾って一言足してから反応する(例:「そんなこと気にしてたんだ」→ 本題に反応する)方が、ちゃんと聞いている印象になるとされる(C)。

### 1-4. 「もう寝る」「今日疲れた」のような会話を終わらせたい合図への返し方
相手が「もう寝る」「今日ちょっと疲れた」のように会話を切り上げたい合図を出した時、「おやすみ」「無理しないでね」だけで終わらせるのが必ずしも正解ではなく、状況によっては短い相槌だけ返す/そのまま自然に流すという指摘がある(C)。逆に、話を引き延ばそうとする内容(「何時起き?」「今日も楽しかった」を長く書く)は温度が下がる要因として挙げられている(C)。この項目は根拠が一つの情報源のみのため、話半分に留めること。

### 1-5. 既読スルー後の対応
既読がついたまま返信がない状態そのものより、**その後にどう振る舞うか**で評価が分かれるという指摘(B)。
- 避けた方がよいとされる対応: 何度もトーク画面を開く/催促のスタンプだけ送る/前に送った内容をもう一度送る/半日後に「元気にしてる?」と探りを入れる
- 良いとされる対応: 返信が来るまで自分の予定を別で埋めておく、返信が来た時に「待たされた」ことを話題にしない、遅れた理由を聞かない

## 2. おもしろ返し・イジりテンプレ

### 型1: 決めつけ+名前ボケ(C)
相手の発言の一部(名前・職業・属性)を大げさな設定に変換して展開する。1〜2往復で切り上げる。

### 型2: 自虐混じりの誇張ボケ(C)
自分を大げさに持ち上げてすぐ落とす。自信と謙虚さの両立。

### 型3: キャラ設定ごっこ(C)
一つの世界観(パパ活・推し活等)を作り、相手が乗ってこなければすぐ普通の会話に戻す。

### 型4: 決めつけ+同意誘導(B寄りバーナム効果に近い)
「絶対〇〇でしょ」と言い切る。肯定でも否定でも会話が続く設計。ポジティブな決めつけに限定する。

### 型5: 行動・反応への軽いイジり(B)
外見やコンプレックスではなく、その場の仕草・反応をいじる。イジった直後にフォロー(「でもそこ好き」)を入れると好感度が上がるという指摘が複数。※「相手が恥ずかしいと感じる部分を意図的に突く」方向に踏み込むと、外見・コンプレックスへのイジりを避けるという大原則(7章参照)に抵触しやすいため注意。あくまで「その場の些細な仕草」に留めること。

### 型6: 質問返し(B)
「彼女いるの?」「モテるでしょ?」のような探りの質問には、即答せず「なんでそう思ったの?」と理由を聞き返す/軽く笑って流す、という返し方が複数のアカウントで共通して推奨されている。動揺・過度な否定を避けるのがポイント。
