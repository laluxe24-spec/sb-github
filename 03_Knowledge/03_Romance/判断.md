# 判断

恋愛・異性関係(脳タイプ差を使う対人場面全般)で「この状況をどう捉えるか」に使える判断材料。りゅーじ君から相談が来たときに、ここから該当しそうな項目を探して使う。会話でどう言うかは`会話.md`、実際にどう動くかは`行動.md`を参照。

## ケース→索引

- 相手の言動が読めない/なぜ距離を置かれるのかわからない → **アタッチメント・タイプを見分ける(黄金のルール)**
- 追いかけると逃げられ、距離を置くと不安になる、を繰り返している → **NタイプとVタイプの悪循環(ジェットコースター効果)に気づく**
- 相手が急に冷たくなる/将来の話を避ける/元恋人に執着している → **離別ストラテジーに気づく**
- 相手に合わせすぎて自分を見失っている/モテるために自分を偽っている → **ファーストラブ理論**
- プレゼントや告白のタイミングで空回りしている → **サプライズ理論**
- 失敗して落ち込んで諦めそうになっている → **エジソン理論**
- 相手の考えていることが理解できない(特に仕事・議論の場面) → **男性脳・女性脳を見分ける5つの視点**
- ほめても響かない/叱ったら関係が悪くなった/報連相がうまく噛み合わない → **脳タイプに合わせて伝え方を変える**

---

### アタッチメント・タイプを見分ける(黄金のルール)
相手(または自分)が親密さにどう向き合うタイプ(S=安定型・N=不安型・V=回避型)かを見分け、不可解に見える言動を予測可能なパターンとして理解する。判断の流れ: ①相手は親密さを求めているか避けているか ②拒否・見捨てられることへの敏感さ ③一度でなく繰り返しのパターンを観察 ④率直な気持ちを伝えた時の反応(最も信頼できる材料。受け止める=S/自分も率直になろうとする=N/「重い」と距離を取る=V) ⑤相手が言わない・しないことにも注目。一度の言動でレッテルを貼らない。
→ リソース: 『異性の心を上手に透視する方法』(原題Attached、アミール・レバイン、レイチェル・ヘラー)
→ 【根拠データ】(実験的観察研究) Ainsworth, M.(1969年前後)「ストレンジ・シチュエーション法」。母親が退室・再入室する場面での乳児の反応を観察し、安定型(約70%)・回避型(約15%)・不安型(約15%)の愛着スタイルを識別した。一度の反応ではなく繰り返し観察されるパターンからタイプを見分ける手法。詳細は`02_Sources/07_Documents/心理学系エビデンス一覧.md`参照

### NタイプとVタイプの悪循環(ジェットコースター効果)に気づく
Nタイプが不安で近づこうとするほどVタイプは息苦しさで離れ、Nタイプの不安がさらに強まる悪循環。表面の話題(元恋人の話等)ではなく根本の「親密さへの欲求の違い」が原因。判断の流れ: ①繰り返す喧嘩・すれ違いのパターンを書き出す ②双方のタイプを推測 ③NとVの悪循環の可能性を検討 ④根本の話し合いができないか考える。タイプで決めつけて関係を諦める理由にしない。DV等深刻な関係には当てはめない。
→ リソース: 『異性の心を上手に透視する方法』

### 離別ストラテジーに気づく
Vタイプ(回避型)は親密になりすぎる不安から、無意識に「相手の欠点ばかり探す」「将来の話を避ける」「過去の恋人に執着」「距離を置く」といった行動(離別ストラテジー)を取る。判断の流れ: ①相手の言動をリスト(小さな欠点への執着/将来の話を避ける/過去の恋人への執着/連絡を急に絶つ/秘密を持つ/身体的接触を避ける)と照らし合わせる ②複数当てはまれば相性でなく親密さへの不安の可能性を考える ③責めず、ペースを落とす・安心を伝える対応を検討。一度二度の行動だけで決めつけない。
→ リソース: 『異性の心を上手に透視する方法』

### ファーストラブ理論
相手の好みに自分を合わせ続けると、同じように合わせている他の人と代わり映えしなくなり「初めての人」になれない。ありのままの自分を貫き、それでも好きになってくれる相手こそ唯一無二の存在になる。判断の流れ: ①相手に合わせている部分を洗い出す ②本当は譲りたくない部分を見つける ③嫌われるリスクを引き受けて出してみる ④それでも受け入れる相手かを見極める。マナー放棄の言い訳にしない、交際初期にいきなり全開放は非推奨。
→ リソース: 『LOVE理論』(水野敬也)終盤「ファーストラブ理論」(別名チンコママ理論)

### サプライズ理論
プレゼントや告白は相手との親密度に見合った量・タイミングでなければ逆効果になる。判断の流れ: ①相手との親密度を振り返る ②考えている行動の大きさを見積もる ③バランスが取れているか確認 ④ズレていれば行動の大きさを調整するか親密度を高めてから行う。相手が明確に距離を置きたいサインを出している時はサプライズで挽回しない。
→ リソース: 『LOVE理論』「サプライズ理論」

### エジソン理論
失敗は「その方法が違うと分かっただけ」であり、人格や価値の否定ではない。判断の流れ: ①うまくいかなかった出来事を振り返る ②「自分がダメ」ではなく「方法が合わなかった」と言い換える ③次に試せる別の方法を考える ④実行する。相手を傷つける行動まで「方法が違っただけ」と繰り返さない。
→ リソース: 『LOVE理論』第1講
→ 【根拠データ】(実験研究) Dweck, C.(スタンフォード大学)。小学5年生400人を対象にした実験で、成功後に「能力」を褒められた子は失敗場面で挑戦を避けやすく、「努力・方法」を褒められた子は失敗しても粘り強く取り組んだ。詳細は`02_Sources/07_Documents/心理学系エビデンス一覧.md`参照

### 男性脳・女性脳を見分ける5つの視点
相手の思考パターンを「競争/共感」「モノタスク/マルチタスク」「論理型/感情型」「最終思考/拡大思考」「自己完結/自己関連」の5視点で見分け、対応を調整する。判断の流れ: ①相手の言動・話し方を観察する ②5つの視点それぞれで傾向を推測する ③一つの手がかりで決めつけず複数を組み合わせる ④判断したタイプに合わせて接し方を調整。「男だから/女だから」と決めつける根拠にしない、あくまで傾向。
→ リソース: 『男女脳戦略。』(メンタリストDaiGo)序章・第1章

### 脳タイプに合わせて伝え方を変える
男性脳は結果・プライド重視で相談は最後(ホウレンソウ)、女性脳は過程・共感重視で相談は最初(ソウレンホウ)が伝わりやすい。判断の流れ: ①男性脳・女性脳を見分ける5つの視点でタイプを推測 ②ほめ方(結果を第三者評価付きでストレートに/過程を同じ立場の評価付きで)を調整 ③叱り方(今のことだけ/話を広げないようフォロー)を調整 ④相談の順番、資料(データ論理/写真感情)を調整。タイプを見誤ると逆効果なので複数の場面で確認する。
→ リソース: 『男女脳戦略。』第1章〜第4章
