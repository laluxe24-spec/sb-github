# 恋愛X投稿のルール

恋愛X投稿プロジェクトのルールは全部このファイルにある。Content(作る)・QA(チェック)・Research(分析)は、作業の前に必ずこれを読む。

## ゴール

Xで恋愛ジャンルの発信をしてフォロワーを伸ばし、**約2000人集まったらnoteの有料記事販売**につなげる。noteへの誘導投稿は2000人まで基本しない。

## 結果の測り方

この2つで測る。どちらも`投稿記録.md`から見る。

1. **りゅーじ君の直しの量が減っていくこと**: Claudeの案と実際に投稿した文を比べて、どれだけ直したか。最終的に「ほぼそのまま投稿できる」状態を目指す
2. **24時間後の表示回数・いいね**: 投稿ごとに記録し、良かった投稿と悪かった投稿の違いを見る

投稿が10本たまるまでは数字の差は偶然の可能性が高いので、1を優先して見る。

## ポジショニング

実績が無い前提で始めるので、「自分はモテる」アピールはしない。「恋愛のテクニックを研究してまとめてる人」という立ち位置(実際そうだから嘘にならない)。

## 回し方

```
Content が`02_Knowledge/01_ネタ/`からネタを選んで、投稿案を3つ作る(朝夜セット)
  ↓
QA が採点(合格ライン90点。届かなければContentに差し戻し)
  ↓
合格した案を 下書き.md の一番上に置く
  ↓
りゅーじ君が選んで・直して・自分でXに投稿する
  ↓
投稿記録.md に「Claudeの案」「実際に投稿した文」「反応」を記録する
  ↓
Research が週1回、投稿記録を分析 → 分かったことを`02_Knowledge/03_成功と失敗/`に残す → 秘書がこのルールを更新
```

## 絶対にやらないこと

- 元ネタ(はやと式・乾式・集めたアカウント)の言い回しをそのまま使う。型だけ使って、文言は毎回作り直す(パクリに見えるため)
- 誇張・断定的な自慢。「女性は必ず〜」のような言い切りの一般化
- りゅーじ君本人の経験・エピソードをClaudeが創作する。必要なら`03_MyKnowledge`から使うか、「ここにりゅーじ君の経験が必要」と書いて渡す
- お手本の形だけをマネする。「なぜ良いのか」を先に言葉にしてから作る
- 一発で全文を書いて終わる。フック→橋渡し→正常化→新しい前提→fix→締めを1パーツずつ組み立てる(一発で書くと「正常化」「新しい前提」が抜けやすい)

## 素材の場所

- **ネタ**: `02_Knowledge/01_ネタ/`(恋愛のフォルダ・`共通テーマ.md`)。「使用: 未」のネタから選ぶ
- **過去の成功と失敗**: `02_Knowledge/03_成功と失敗/`(同じ失敗をしないために必ず読む)
- **書き方の技術**: `02_Knowledge/04_ノウハウ/ここな式.md`

- **りゅーじ君自身の考え・経験**: `03_MyKnowledge/02_自分の考え/`
- **元データ**: `01_Sources/02_X/data/`のアーカイブ

## 投稿の形(朝夜2本セット)

朝は「具体的な行動」、夜は「その行動の裏にある心理と、変わり方」。夜は朝のテーマを深掘りする。どちらも本文で途中まで見せて、続きを返信欄(コメント欄)に置く(ここな式の「答えをコメント欄に置く」技術)。

### テーマの選び方

**2つ以上のアカウントで共通して触れられているテーマ**を選ぶ(アーカイブで確認)。学術的な裏付けはいらない。「確かにこれあるある」と思える納得感があれば十分。恋愛系Xは同じテーマ(既読無視・束縛・沈黙など)を無数のアカウントが繰り返して伸びているジャンルなので、テーマの目新しさは気にしない。

よく出るテーマ: 会話 > 女性心理の解説 > 告白 > LINE > 初デート > 駆け引き・長期的な関係 > 誘い方

### 朝投稿の型

集めた3583件の分析で、「■悪い例/■良い例」の対比型は**全体の3%しかない少数派**だった。対比型をデフォルトにしない。

使う型(テーマに一番合うものを選び、同じ型を連続で使わない):
- **NG行動だけ型**: 悪い行動だけを並べて指摘する(実際に一番多い切り口)
- **成功行動だけ型**: 良い行動だけを見せる
- **絵文字ランク型**: 🥇🥈🥉や❌⭕で3段階に分ける
- **NGランキング型**: 「NG行動TOP3」
- **エピソード型**: 状況→セリフ→余韻、で終わる短い物語
- **問いかけ締め型**: 「あり?なし?」で読者に委ねる
- **対比型**: ■悪い例→■良い例。4〜5投稿に1回まで

朝投稿のルール:
- 箇条書きには鍵カッコの具体的なセリフを最低1つ入れる(実際の投稿の約3分の1がセリフ入り。抽象的な行動描写だけで終わらせない)
- タイトル・見出しのラベルは毎回テーマ固有の言葉にする(「冷められる男性/好印象な男性」を使い回さない。例: 追う/追わない、重い/信頼される)
- タイトルの文型も毎回変える(断定・意外性・引用など)
- 「結局この3つに共通してるのは〜」の締め文は付けない(実際の投稿の79%は、箇条書き+短いまとめの矢印だけで終わる)
- 「女性からすると〜と感じる。逆に〜」の文型を毎回使わない

対比型を使う時だけ:
- 良い側の各行に「〜でも」「〜だけど」のような内面の譲歩表現を入れない(行動描写だけにする)
- 悪い側の各項目と良い側の各項目を1対1で対応させる(同じ状況での代わりの行動にする)

### 夜投稿の型

**本文(3文)**: 症状 → 隠れた原因 → 再定義
1. 行動の描写(朝の悪い行動をしてしまう人に語りかける)
2. その原因をひと言でラベル化する
3. 「性格/相性の問題じゃない。仕組みを知れば変わる」

**返信欄**: 心理学カード(`03_MyKnowledge/03_使える知識/01_Psychology/`など)の判断の流れを、番号のまま見せず文章に溶かす。順番はこう。
1. **感情の正常化**: 「その気持ち自体は悪くない、誰にでもある」に当たる1文。**一番抜けやすい**
2. **新しい前提**: 読者が「なるほど、知らなかった」と思える事実・免罪符(例: 「全員に好かれるのは無理」)。本文の言い換えは不合格。**これも抜けやすい**。これが無いと次のfixがただの命令になる
3. **fix**: 「だったら〜すればいい」。直前の前提から「だから」で自然につながること
4. **締め**: 朝投稿の言葉と呼応させる。責めない・前向きな一言で終わる

心理学は、アカデミックな概念より「心理的リアクタンス(追われると逃げたくなる)」「愛着」「感情調整」のような、恋愛アカウントで実際によく使われている概念を優先する。

## 公開前チェックリスト(QAが採点に使う)

1. テーマが2つ以上のアカウントで触れられているか
2. 朝の型が直前の投稿と違うか。対比型が続いていないか
3. 朝の箇条書きに鍵カッコのセリフが1つ以上あるか
4. タイトル・ラベルがテーマ固有の言葉で、文型が前回と違うか
5. (対比型の時)良い側に譲歩表現が無く、悪い側と1対1で対応しているか
6. 夜の本文が「症状→原因→再定義」の3文か
7. 夜の返信欄の冒頭が、本文の言い換えになっていないか
8. 感情の正常化があるか
9. 新しい前提があり、それが本文の言い換えではない新情報か
10. fixが「だったら」で直前の前提から論理的につながるか
11. 夜の締めが朝の言葉と呼応しているか
12. 元ネタの言い回しそのまま・誇張・言い切りの一般化・創作エピソードが無いか

構造(1〜11)を全部満たしても、それだけで100点にはならない。過去の検証では、構造を満たしても「新しい前提」が弱いと74点止まりだった。9番を特に厳しく見る。

## 100点のお手本

りゅーじ君が手直しして100点をつけた朝夜セット。**形をマネするのではなく、下の「なぜ100点か」を真似する。**(朝の対比型は、今は4〜5投稿に1回までの型)

**朝・本文**
```
デート中の態度で冷められる男性

■冷められる男性の特徴
・店やメニューを毎回女性に選ばせる
・沈黙が怖くて喋り続ける
・女性の反応を逐一確認する
→頼りないと思われて終わる

■逆に、好印象な男性は
```

**朝・返信欄**
```
・自分から店や流れを決める
・沈黙が来ても気まずがらない
・反応を確認せず自然体でいる
→一緒にいて安心できる人になる

女性からすると、決断を任せられる人は「一緒にいて楽」と感じる。逆に何でも選ばせてくる人は、頼りなさが目について冷めてしまう。
```

**夜・本文**
```
デートで冷められる人ほど、実は"優しい"つもりでいる。

「嫌われたくない」が、決断も沈黙も怖くさせてる。

これ、性格の問題じゃない。ある考え方を知るだけで変わる。
```

**夜・返信欄**
```
まず、動けない原因が「嫌われたくない」気持ちだと認める。
その気持ち自体は悪くない、誰にでもある。

ただ、全員に好かれるなんてそもそも無理な話。
店選びで多少ズレたところで、それだけで嫌われることはまずない。

だったら、嫌われるリスクを払ってでも、自分の選びたい方を選べばいい。
「この人は自分で決められる人なんだ」って、それだけで印象は変わる。

結局、好印象な人がやってるのは、反応を伺う前に自分で決めること。それだけ。

気づけただけで、もう半分変わってる。
```

### なぜ100点か

- **タイトル**: 硬い言葉を使わず、0.2秒で何の話か分かる
- **朝の3項目**: 性格ではなく具体的な行動なので、読者が自分と照らし合わせられる。3つは多すぎず少なすぎないバランス
- **朝の本文の切り方**: 答え(良い行動)の見出しだけ出して止めるので、続きが気になって返信欄を開く
- **女性目線の一文**: 「これをやれ」だけでなく、女性がどう感じるかまで書く。他の「モテテク」アカウントとの差別化になる(りゅーじ君の指示で追加した要素)
- **夜のフック**: 責めるのではなく「優しいつもり」という本人の自己認識を突く
- **夜の2文目**: 「嫌われたくない」で、朝の3つの悪い行動の共通の根っこを明かす
- **夜の3文目**: 「直し方がある」と言い切らず「ある考え方を知るだけで変わる」で期待を持たせる
- **夜の返信欄**: `嫌われる勇気.md`の「承認欲求を手放す」カードの流れ(①原因を認める ②否定しない ③全員に好かれるのは無理 ④コストを払っても選ぶ)を、番号を見せずに文章に溶かしている。途中の店選びの具体例で抽象論で終わらせない
- **締め**: 朝の言葉と呼応させて朝夜の一体感を出し、最後は責めない前向きな一言で温度をそろえる
