# X投稿のルール

## 構造(content-aiが使う)

1つのテーマを、朝→朝返信→夜→夜返信の4つに分けて、1本の流れとして作る。

- 朝: 正しい行動を教える
- 朝返信: 具体的な答えを出す
- 夜: 非モテが無意識にやっている思考を1つ見せる(下の「夜の書き方」)
- 夜返信: 女側の感じ方と、考え方を1行だけ反転させる

本文(朝・夜)は途中で切って、続きを返信欄に書く。

## 書き方(content-aiが使う・2026-09-25)

1投稿＝1テーマ。そのテーマの中の「モテ/非モテの分かれ道」を1つだけ扱う。別の分かれ道は混ぜない(例: 断られた後の投稿に「日にちを2択で」を入れない)。分かれ道は`02_Knowledge/01_ネタ/恋愛/テーマ別モテテク.md`から選ぶ。

「教える投稿」ではなく「体験させる投稿」にする。書く順番は決めない。毎回入れるもの:
1. **読者がいつもやっている小さな動作・セリフ**を1つ。悪役の性格ではなく、良かれと思ってやっていること(例: 沈黙のあと慌てて「最近ハマってることある？」/「忙しかった？笑」)
2. **女性の声**: 非モテ側・モテ側それぞれ1つまで。理由は説明せず、体感で言う(「正直ちょっと重い」「こっちまで気をつかい始める」)
3. **持ち帰れるもの**: そのまま真似できる行動・セリフ(3個まで)。本文だけでも1つ持ち帰れるようにする
4. **続きに残すもの**: 本文から推理できない答え

形(どう見せるか)は毎回変える。下の「フックの型」20個から選び、同じ形を2日続けない。「〜してない？」→女性の声→行動3つ→「〜なくていい」の形ばかりにしない(9/25の反省)。
- 例: ランキング型(TOP3)・大好物型・サイン型・問いかけ型・会話だけで見せる・観察(「〜な男、多い」)
- 型より、そのテーマの空気を優先する(余裕がテーマなら「今度行こ」くらい軽く。誘い方がテーマなら日にちを2択で)

出す前に見る(AIっぽさのチェック):
- 主人公は読者か(「女友達が〜」の他人の話にしない)
- 結果を書き手のまとめ言葉で言っていないか(✕「ループしてバグる」→ ◯「『私のこと好きなの？』って考えちゃう」)
- 理由を説明していないか(✕「決める手間が減るから」→ ◯「〜のほうが楽」)
- 心の声をカッコで横に添えていないか(文の流れの中に「〜ってなる」で入れる)
- 「逆に〜はNG」と説教していないか。読者を見下して締めていないか
- ハードルを上げていないか(「完璧に」「絶対」より「〜だけ」)
- 本文だけでも1つ持ち帰れるものがあるか。続きの答えが本文から推理できてしまわないか
- **捏造していないか**: 数字・順位・テクニック・女性の声は、`テーマ別モテテク.md`か`モテと非モテの基準.md`にあるものだけ使う。ランキングの順位は件数の順にする。無いものを足した時は、報告で必ず言う(9/25に「最後の30分」「店は任せる」を作ってしまった)
- 本文・返信欄それぞれ140字以内か

お手本: `下書き.md`の一番上の3本(沈黙・断られた後・誘い方。りゅーじ君がOKした完成版)。見るのは言葉の温度と女性の声の入れ方。3本とも似た形なので、形は真似しない
根拠: `02_Knowledge/02_分析/恋愛Xの伸びる投稿.md`の「0. 読まれる文章の原理」

## 夜の書き方(非モテ思考ルール・りゅーじ君が決めた・2026-09-25)

各投稿には、「非モテが無意識にやっている思考」を1つ入れる。
ただし、心理学を説明しない。「○○効果」「認知バイアス」などの専門用語は禁止。

書く順番:
1. 非モテが陥る思考を一言で書く
2. その思考が会話や行動でどう出るか見せる
3. 女側がどう感じるかを短く見せる
4. 考え方を1行だけ反転させる

例:
- 悪い例「選択肢を減らすと返しやすくなる。」→ 良い例「断られたら嫌われたって考える。」
- 悪い例「心理的負担が減る。」→ 良い例「決めるのは相手。出すのは日にちだけ。」

目的は、テクニックを説明することではない。読者が「俺、その考え方してた」と気づく文章を書く。
**思考の癖は、`02_Knowledge/01_ネタ/恋愛/非モテの4タイプ.md`の4タイプ(他人軸型・相手が見えてない型・不安で追う型・聞き下手型)から1つ選ぶ。直し方もそこに書いてある考え方を使う。**
本文に1〜2、返信欄(折りたたみ)に3〜4を置く。

思考と反転のネタ元(`03_MyKnowledge/03_使える知識/01_Psychology/`・`02_Romance/異性の心を上手に透視する方法.md`。読むだけ。用語は投稿に出さない。『LOVE理論』『男女脳戦略』は使わない):

| 非モテの行動 | 無意識の思考 | 反転の元になる考え方 |
|---|---|---|
| 追いLINE・返信を待ちすぎる | 返信が来ない＝嫌われた | 不安は事実じゃなく予想(こころが晴れるノート)/返すかは相手が決める(嫌われる勇気) |
| 断られた後に食い下がる・落ち込む | 断られた＝自分を否定された | 決めるのは相手、自分ができるのは出すところまで(嫌われる勇気) |
| 「可愛いね」しか言えない・全部合わせる | 外したら嫌われる | 全員に好かれるのは無理(嫌われる勇気) |
| 解散できない・粘る | 今日帰したら次はない | 不安は事実じゃなく予想。根拠を探すと逆が多い(こころが晴れるノート) |
| 「自信がないから」誘えない | 自信がついたら動ける | 本当は傷つくのを避けたいだけ(嫌われる勇気) |
| 不安で近づくほど相手が離れる | もっと連絡すれば安心できる | 追うほど相手は息苦しくなる(異性の心を上手に透視する方法) |

お手本: `下書き.md`の夜の3本(褒め方・別れ際・誘い方)

〇〇に入れるもの:
- 広い言葉(会話・優しさ・褒め方)ではなく、具体的な1場面・1つのモノ(カラオケの曲選び・久しぶりのLINE・スタバデートなど)
- テーマは「付き合うまで」(誘い方・告白・脈あり・LINE・デート中)

言い回し:
- 言い切る。「と思う/かも」「実は/正直」「結論」は使わない(1行目の話。本文や返信欄の「正直ちょっと重い」のような体感の言い方はOK)
- 1行目を「」のセリフで始めない。「君/あなた」と呼びかけない
- 使わない言葉: 優しい・非モテ・恋愛・理由・9割の男

性別の呼び方:
- 「男性/女性」と「男/女/女子/女の子」を投稿ごとに使い分ける
- どちらが伸びるかは、りゅーじ君の投稿の数字で決める

## リサーチの条件(research-aiが使う)

- バズの条件: 本体の表示回数10万以上・続きの読まれ率(続きの表示回数÷本体の表示回数)10%以上
- 投稿の形: 本体140字以内＋自分の返信欄に続き
- 検索キーワード: 会話・女性心理・告白・LINE・初デート・駆け引き・誘い方・脈あり
- 分析の保存先: `02_Knowledge/02_分析/恋愛Xの伸びる投稿.md`

10万・10%は、@mirei_uratekuの1週間分を見て決めた仮の数字。最初のリサーチで候補が多すぎ/少なすぎたら直す。
