## 「謙遜」の口ぐせ(朝夜セット・9/24作成・QA採点94点で合格・NGランキング型)

```
第2位

```

**朝返信**
```
第1位

→経験の少なさより、それを先に言っておく方が目につく

```

**夜メイン**
```
褒められたら「たまたま」、誘う時は「よければだけど」、会えば「慣れてなくて」。

それ全部、断られる前に自分で自分を下げておく「予防線」になってる。

```

**夜返信**
```
先に自分を下げたくなるのは、傷つきたくないのと同じくらい、ちゃんと相手に気をつかえる人だから。
その感覚自体は、悪いものじゃない。

実際、謙遜は仕事みたいに上下がある場では立派な礼儀。
ただ、対等でいたい恋愛の場だと、同じ一言が「持ち上げてほしい」というお願いに聞こえてしまうことがある。
つまり、直すのは性格じゃなくて、使う場所だけ。

だったら、恋愛の場では謙遜の礼儀をいったんしまえばいい。
褒められたら、打ち消さずに「うれしい」で受け取って、話を続ける。

誘う時は、「よければだけど」を付けずに「一緒に行きたい」とだけ言う。

慣れてないことはすぐには変えられないけど、先に言うかどうかは今日から選べる。「慣れてなくて」の代わりに、「ここ、前から気になってたんだ」とその場の話をすればいい。

次に褒められたら、「たまたま」と言う前に「うれしい」。その一言から、口ぐせは変わっていく。
```
