## 朝・返信欄

```
・自分から店や流れを決める
・沈黙が来ても気まずがらない
・反応を確認せず自然体でいる
→一緒にいて安心できる人になる

女性からすると、決断を任せられる人は「一緒にいて楽」と感じる。逆に何でも選ばせてくる人は、頼りなさが目について冷めてしまう。

結局この3つに共通してるのは、相手の反応を伺う前に自分で決めてること。
それだけで「一緒にいて安心できる人」に見える。
```

## 夜・本文

```
デートで冷められる人ほど、実は"優しい"つもりでいる。

「嫌われたくない」が、決断も沈黙も怖くさせてる。

これ、性格の問題じゃない。ある考え方を知るだけで変わる。
```

## 夜・返信欄

```
まず、動けない原因が「嫌われたくない」気持ちだと認める。
その気持ち自体は悪くない、誰にでもある。

ただ、全員に好かれるなんてそもそも無理な話。
店選びで多少ズレたところで、それだけで嫌われることはまずない。

だったら、嫌われるリスクを払ってでも、自分の選びたい方を選べばいい。
「この人は自分で決められる人なんだ」って、それだけで印象は変わる。

結局、好印象な人がやってるのは、反応を伺う前に自分で決めること。それだけ。

気づけただけで、もう半分変わってる。
```
