# Xアーカイブ構成分析の手順書

`02_Sources/02_X/data/`に集めた恋愛系Xアカウントの投稿アーカイブから、「テーマ×切り口×構成×具体性×心理学概念」の引き出し(構成データベース)を作る手順。目的は、投稿をそのまま真似ることではなく、今後の投稿生成で使える型のバリエーションを増やし、特定の構成(対比型など)がデフォルト化するのを防ぐこと。

## STEP1: 機械分類(全件)

```bash
cd 05_Projects/content
python3 scripts/classify_archive.py
```

アーカイブ全件を構成タイプ(対比型/短文型/箇条書き型/会話例型/番号リスト型/問いかけ型/その他)で機械的に分類し、頻度を表示する。正規表現ベースなので全件(3000件超)に対して一瞬で終わる。ここで「どの構成がどのくらいの割合か」の正確な分布が分かる。

## STEP2: 層化サンプリング

```bash
python3 scripts/classify_archive.py --sample 200
```

STEP1の構成タイプごとに比例配分したサンプルを作る(少数派タイプも最低件数を確保、文字数の外れ値も追加で含める)。単純なランダム抽出ではなく、**構成タイプの分布に偏りが出ないように層化する**のが重要(多数派の構成だけがサンプルされると、少数派の使える型を見逃す)。`scripts/_sample_output.json`に出力される。

## STEP3: 深掘り分類(サブエージェントで並列処理)

STEP2のサンプルを2〜3個のJSONファイルに分割し、`scratchpad`に保存した上で、同数のサブエージェント(Agent tool、`general-purpose`)に並列で投げる。各サブエージェントには以下を分類させる:

- **A. テーマ**: 何について書いているか(初デート・LINE・告白など。既存カテゴリに無理に当てはめず新規追加可)
- **B. 切り口**: どう伝えているか(NG行動・成功行動・意外な事実・女性側の受け取り方など。テーマとは分離して抽出する)
- **D. 具体性**: 抽象的なアドバイス/具体的な行動/具体的なセリフ/具体的な状況/具体的な心理、のどれか
- **E. 心理学・行動原理**: 投稿に明確な根拠がある場合のみ付与する(心理的リアクタンス・損失回避・確証バイアス・自己呈示・単純接触・帰属・感情調整・不安・愛着など)。無理に付与しない、根拠が弱ければ「心理学概念なし」とする。

出力は「id: テーマ/切り口/具体性/心理学概念」の圧縮テーブル形式(1行ずつ)+チャンクごとの集計サマリー(200字程度)。プロンプトの詳細テンプレートは、直近の実行例(2026-09-23、下記参照)をそのまま使い回せる。

## STEP4: 集計とルール化

3つのサブエージェントの結果を合算し、以下を作る(Pythonで頻度集計、最終ドキュメントは手書き):

1. 構成タイプの分布(STEP1の全件データ)
2. 切り口の分布(STEP2〜3のサンプルデータ)
3. 具体性レベルの分布
4. 心理学・行動原理の分布(何が実際に使われているか)
5. 頻出テーマ
6. 対比型以外の再利用可能な"型"一覧(絵文字ティア型、NGランキング型、エピソード型など、サブエージェントの集計サマリーから拾う)
7. 今後避けるべきマンネリパターン
8. 構成・切り口の選択ルール(次に投稿を作る時、機械的に確認できるルールにする)

最終アウトプットは`05_Projects/content/`直下に`<テーマ>_構成データベース.md`として保存する。
