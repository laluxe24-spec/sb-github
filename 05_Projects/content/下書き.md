# 投稿下書き

### パターンG: デート中の態度で冷められる男性

**本文**
```
デート中の態度で冷められる男性
```
→ **タイトルの意図**: 「格下/格上」のような硬い言葉を使わず「〜で冷められる男性」という中立的な言い方にした。0.2秒で何の話か分かる、シンプルなラベル。

```
■冷められる男性の特徴
・店やメニューを毎回女性に選ばせる
・沈黙が怖くて喋り続ける
・女性の反応を逐一確認する
→頼りないと思われて終わる
```
→ **意図**: `Todai_Renai`の実投稿(アーカイブ209件中で最多パターン)から抽出した「■見出し+・3項目+→まとめ」の型。3項目にした理由は、多すぎると読み飛ばされ、少なすぎると説得力が弱いバランス。各項目は具体的な行動(抽象的な性格描写ではない)にして、読者が自分の行動と照らし合わせやすくした。「→まとめ」で一言の結果(頼りないと思われる)を示し、感情的な重みを持たせている。

```
■逆に、好印象な男性は
```
→ **意図**: ここが本文の切れ目。答え(好印象な男性の行動)を明かさずに見出しだけ出すことで、続きが気になる状態を作り、返信欄への遷移(タップ)を狙う(ここな式の「答えをコメント欄に置く」技術)。

**返信欄**
```
・自分から店や流れを決める
・沈黙が来ても気まずがらない
・反応を確認せず自然体でいる
→一緒にいて安心できる人になる
```
→ **意図**: 本文の3つの悪い行動と1対1で対になる良い行動を並べ、比較しやすくした。

```
女性からすると、決断を任せられる人は「一緒にいて楽」と感じる。逆に何でも選ばせてくる人は、頼りなさが目について冷めてしまう。
```
→ **意図**: 行動の説明だけで終わらせず、女性側がその行動をどう感じるかまで書いた部分(りゅーじ君の指示で追加した要素)。単なる「これをやれ」ではなく「なぜそれが効くのか」を伝えることで、他の「モテるテクニック」系アカウントとの差別化になる。

```
結局この3つに共通してるのは、相手の反応を伺う前に自分で決めてること。
それだけで「一緒にいて安心できる人」に見える。
```
→ **意図**: 3つの行動をバラバラのまま終わらせず、1本の原則にまとめる結論。最初のドラフトでは「会話の上手さより〜」という、本文で触れていない新しい話を持ち出して唐突になった反省から、**必ずその投稿で書いた3つの行動だけを根拠に結論を出す**ように直した。

## 夜(サンプル、2026-09-23作成)

朝の「冷められる男性」パターンにフォーカスして作った、夜投稿の完成サンプル。構成の意図を各パーツに注釈した。

**本文**
```
デートで冷められる人ほど、実は"優しい"つもりでいる。
```
→ **フックの意図**: 朝投稿で「冷められる行動」をした人自身に、直接語りかける。「優しいつもり」という言葉で、責めるのではなく本人の自己認識(自分では優しさだと思っている)を突く。Xをパーっと見てる人が立ち止まって、プロフィールを押したくなる強さを狙った一文。

```
「嫌われたくない」が、決断も沈黙も怖くさせてる。
```
→ **意図**: フックで匂わせた「優しいつもり」の正体を、ここで明かす。読者の中で「あ、それだ」という自己認識が起きる瞬間。

```
これ、性格の問題じゃない。ある考え方を知るだけで変わる。
```
→ **意図**: 「直し方がある」と直接的に書くとぶっきらぼうになるため、「ある考え方を知るだけで変わる」という期待を持たせる書き方にした。答えを言い切らずに返信欄へ誘導する(ここな式の技術)。断定は避けつつ、返信欄の中身(承認欲求のカード)と矛盾しない表現にしてある。

**返信欄**

**心理学カードの使い方**: `嫌われる勇気.md`の「承認欲求を手放して自由に生きる」カードを選んだ理由は、朝投稿の3つの悪い行動(店選びを任せる/沈黙が怖い/反応を伺う)が、どれも「嫌われたくない」という1つの根っこから来ていると判断したため。カードの判断の流れ①②③④を、番号のまま見せず文章に溶かして使った。対応関係はこう。

| カードの判断の流れ | 返信欄の対応箇所 |
|---|---|
| ①動けない理由に承認欲求があるか確認 | 「まず、動けない原因が『嫌われたくない』気持ちだと認める。」 |
| ②「嫌われたくない」自体は否定しない | 「その気持ち自体は悪くない、誰にでもある。」 |
| ③全員に好かれることは不可能だと確認 | 「ただ、全員に好かれるなんてそもそも無理な話。」+店選びの具体例で補強 |
| ④本当にやりたい選択肢を選び、コストを払ってでも進む価値があるか判断する | 「だったら、嫌われるリスクを払ってでも、自分の選びたい方を選べばいい。」 |

```
まず、動けない原因が「嫌われたくない」気持ちだと認める。
その気持ち自体は悪くない、誰にでもある。

ただ、全員に好かれるなんてそもそも無理な話。
店選びで多少ズレたところで、それだけで嫌われることはまずない。

だったら、嫌われるリスクを払ってでも、自分の選びたい方を選べばいい。
「この人は自分で決められる人なんだ」って、それだけで印象は変わる。

結局、好印象な人がやってるのは、反応を伺う前に自分で決めること。それだけ。

気づけただけで、もう半分変わってる。
```
→ **意図**: 中身は`嫌われる勇気.md`の「承認欲求を手放して自由に生きる」カードの判断の流れをベースに、文章として溶かしたもの(①〜④を番号のまま見せず、自然な文章の流れに変換)。途中で店選びの具体例を入れて抽象論で終わらせないようにした。最後は朝投稿の結論(「結局この3つに共通してるのは〜」)と同じ言い回しで呼応させ、朝夜のセットである一体感を出した。締めは「同じタイプの人いる?」のような直接的な問いかけではなく、「気づけただけで、もう半分変わってる」という前向きな一言にした(投稿全体のトーンが「責めない・優しい」で統一されているため、最後だけ強く言い切ると温度感がズレるという判断)。
