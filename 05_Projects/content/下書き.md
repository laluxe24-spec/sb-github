### 距離を置かれた時の反応(朝夜セット・QA採点74点)

**朝メイン**
```
距離を置かれた時、追うか手放すかで印象が決まる。

■追うほど「うざい」と思われる男性
・既読無視されるほど連絡の頻度を増やす
・会えない理由を根掘り葉掘り聞く
・「最近冷たくない?」と問い詰める
→追われるほど逃げたくなる

■逆に、追わなくても「気になる」と思われる男性は
```

**朝返信**
```
・既読無視されても、いつも通りのペースで連絡する
・会えない理由を深追いせず「了解」で流す
・態度の変化を責めずに、自分の予定に集中する
→追わない人ほど逆に気になる存在になる

女性からすると、距離を置いても態度を変えない人は「自立してる」と感じて安心する。逆に距離を置いた瞬間に追いかけられると、息苦しくて余計に離れたくなる。
```

**夜メイン**
```
距離を置かれるほど、追いかけたくなる。

それ、不安に耐えられなくて動いてるだけかもしれない。

これ、相性の問題じゃない。この仕組みを知れば抜け出せる。
```

**夜返信**
```
追いかけたくなる気持ち自体は、おかしくない。人は不安になると、確かめたくなる生き物だから。

ただ、追われるほど人は本能的に距離を取りたくなる。これは相性じゃなくて、ただの仕組み。

だったら、追いたくなった時こそ、あえて自分の時間に意識を向ければいい。

結局、追わなくても気になる人がやってるのは、不安を相手にぶつけないこと。それだけ。

それに気づけた時点で、もう半分抜け出せてる。
```

### 友達付き合いへの干渉(朝夜セット・QA採点82点)

**朝メイン**
```
友達付き合いに口を出す男性ほど、信頼されない。

■口を出しすぎて「重い」と思われる男性
・誰と遊ぶか逐一聞きたがる
・女友達との連絡を制限したがる
・「その人と会うのやめてほしい」と言う
→束縛だと思われて終わる

■逆に、干渉しなくても「信頼される」男性は
```

**朝返信**
```
・誰と遊ぶかは基本聞かない
・女友達との連絡も本人に任せる
・言いたいことは制限ではなく素直な言葉で伝える
→信頼して任せてくれる人だと感じてもらえる

女性からすると、交友関係を任せてもらえると「対等に見てもらえてる」と感じて安心する。逆に誰と会うか管理されると、恋愛してるはずなのに自由を奪われてる気分になる。
```

**夜メイン**
```
友達付き合いに口を出したくなるほど、実は不安なだけ。

それ、相手の課題に自分が土足で踏み込んでるだけかもしれない。

これ、独占欲の強さの問題じゃない。区別の仕方を知れば変わる。
```

**夜返信**
```
誰と仲がいいのか気になる気持ち自体は、おかしくない。好きなら気になるのは自然なこと。

ただ、相手が誰と付き合うかは、そもそも相手の課題。踏み込んだところで自分がコントロールできることじゃない。

だったら、気になる気持ちは自分の中で扱って、相手の交友関係には口を出さないと決めればいい。

結局、信頼できる人がやってるのは、相手の課題に踏み込まないこと。それだけ。

それを区別できた時点で、もう束縛から抜け出せてる。
```
