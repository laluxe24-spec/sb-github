# AI組織図

sb-macで動くAI全体の基本構造。

## 基本

中心になるのは秘書AI。りゅーじ君からの依頼・会話・新しい情報・蓄積したKnowledgeを見て、自分で処理するか、機械的な作業をさせるか、サブエージェントを呼ぶかを判断する。

## 秘書AI

考える・判断する・指示する・統合する。単なる受付や振り分け役ではなく、状況を理解した上で自分でできることは自分で処理する。research-aiの分析を見て戦略案を出す、content-aiが作ったものに修正案をつける、りゅーじ君がOKしたらルールを書き換える、のも秘書AIの仕事。やることが複数ある時は、影響が大きい順に並べて進める。

## 機械的な作業(AI判断は基本不要)

決められた処理を実行するだけの仕事。情報の取得(X・TikTok・Threads・Instagram・Web・Kindleなど)、ファイルの整理・移動、決められた形式への変換など。launchd・API・Playwright・yt-dlpなどを使って自動実行する。

## サブエージェント(必要なときだけ呼ぶ、4人)

専門的な判断・分析・制作が必要なときだけ、秘書AIが呼び出す。常に独立して動いているわけではない。指示書は`.claude/agents/`にある(Claude Codeが正式にサブエージェントとして呼べる場所)。

人はプロジェクトごとに増やさない。4人は全プロジェクト共通で、プロジェクトごとの違い(ゴール・「結果」の測り方・ターゲット・100点の基準)は`04_Projects/<プロジェクト>/ルール.md`に書き、各担当が毎回それを読んで動く。

- **research-ai(副業専門のアナリスト)**: 何を調べるか・どんな切り口で見るかから自分で考えて提案する。バズ投稿探し・参考アカウントの入れ替え提案・なぜ伸びた/伸びていないかの分析・自分の投稿の振り返り。分かったことを`02_Knowledge`に残す → `.claude/agents/research-ai.md`
- **content-ai(プロの書き手)**: `02_Knowledge`とプロジェクトのルールから、投稿・記事・台本を作り、「こうしたらもっと良くなる」も提案する → `.claude/agents/content-ai.md`
- **mentor-ai(りゅーじ君専門)**: 集めた元データから、りゅーじ君が恋愛・仕事・生活で使える知識を作って`03_MyKnowledge`に残す → `.claude/agents/mentor-ai.md`
- **qa-ai(お休み中)**: りゅーじ君が頼んだ時だけ → `.claude/agents/qa-ai.md`

サブエージェント同士は直接やり取りできない。受け渡しは必ず秘書AIが行い、その中で完結させる(途中経過でりゅーじ君を都度巻き込まない)。

新しいことを始める時(例: ポケカ)は人を増やさず、秘書AIがresearch-aiに調べさせた上で、`04_Projects/<プロジェクト>/ルール.md`と必要なスキルを作る(りゅーじ君の確認が必要)。

## 全体の流れ

```
collect(元データを集める。使い道はここでは決めない)
   │
01_Sources(元データ)
   ├──→ research-ai(副業の分析) ──→ 02_Knowledge(ネタ・分析・成功と失敗)
   │                                        │
   │                                 秘書AI(戦略案) → りゅーじ君が決める → ルールに書く
   │                                        │
   │                                 content-ai(作る) → 秘書AI(修正案) → りゅーじ君が投稿
   │                                        │
   │                                 research-ai(反応を分析) → 次に反映(PDCA)
   │
   └──→ mentor-ai(りゅーじ君の成長) ──→ 03_MyKnowledge
```

1つのフォルダにつき、作る担当は1人: `01_Sources`=collect、`02_Knowledge`=research-ai、`03_MyKnowledge`=mentor-ai、`04_Projects`の下書き=content-ai(ルールは秘書AI)。

秘書AIの動き方のルールは、sb-mac直下の`CLAUDE.md`にある。
