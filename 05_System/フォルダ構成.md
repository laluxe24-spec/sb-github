# フォルダ構成(sb-macの地図)

どこに何があるかは、このファイルを見れば分かる。置き場所を変えたら、ここも一緒に直す。

## 一番上

| フォルダ・ファイル | 中身 |
|---|---|
| `CLAUDE.md` | 全体のルール・秘書AIの動き方 |
| `.claude/agents/` | サブエージェント4人の役割 |
| `.claude/skills/` | 手順書(スキル) |
| `01_Sources/` | 外から集めた生データ |
| `02_Knowledge/` | 副業を成功させるための知見(ネタ・分析・成功と失敗・ノウハウ) |
| `03_MyKnowledge/` | りゅーじ君のためのもの(自分の考え・自分用の知識・AI学習メモ) |
| `04_Projects/` | 発信などのプロジェクト(ルール・下書き・記録) |
| `05_System/` | 地図・組織図・TODO・更新履歴・毎朝の自動実行 |

## サブエージェント(`.claude/agents/`)

| 名前 | 仕事 |
|---|---|
| `research-ai` | 副業専門のアナリスト。調べる・分析する・02_Knowledgeに残す |
| `content-ai` | プロの書き手。投稿・記事・台本を作って提案する |
| `mentor-ai` | りゅーじ君の成長のための知識を03_MyKnowledgeに残す |
| `qa-ai` | お休み中(りゅーじ君が頼んだ時だけ) |

誰がどうつながるかは`05_System/AI組織図.md`。

## スキル(`.claude/skills/`)

| スキル | 何をする | 主に使う人 |
|---|---|---|
| `collect` | 元データを集める(X・TikTok・YouTube・Kindle。媒体ごとにファイルが分かれてる) | 秘書・自動実行 |
| `research` | 副業の調査・分析と02_Knowledgeへの保存(`X.md`・`結果分析.md`・`残し方.md`) | research-ai |
| `content` | 発信するものを作る・直す(媒体ごとにファイルが分かれてる) | content-ai・秘書 |
| `my-knowledge` | りゅーじ君用の知識を作る(はやとさん=会話の分析、乾さん=営業トークの分析、本など) | mentor-ai |
| `izuna-monthly` | イズナの交通費入力・カレンダー登録(月次) | 秘書 |

## 01_Sources(生データ)

| フォルダ・ファイル | 中身 |
|---|---|
| `収集リスト.md` | 「追いかけている人」と「気になっている人(まだ追いかけていない)」の一覧。役割・何のために入れたかつき |
| `01_Kindle/data/<本>/本文.md` | Kindle本のOCR全文 |
| `02_X/data/@<アカウント>/` | Xの投稿(`posts.json`=全文・表示回数・いいね。`profile.json`=フォロワー数・作った日の履歴) |
| `02_X/候補/<プロジェクト>/@<アカウント>/` | リサーチのために仮で集めた人(毎朝の自動収集には入らない) |
| `02_X/data/@kw1ew/スクショ/` | kw1ewの会話スクショ(厳選済み) |
| `03_TikTok/data/@<アカウント>/transcripts/` | TikTokの文字起こし |
| `04_YouTube/data/@<チャンネル>/transcripts/` | YouTubeの文字起こし |
| `05_Instagram/` | Instagram用(まだ空。集め始めたらここに入れる) |
| `06_Threads/` | Threads用(まだ空。集め始めたらここに入れる) |

各フォルダの`scripts/`は収集・文字起こしのプログラム。使い方はスキル(`collect`・`transcribe`)に書いてある。生データの分析結果はここには置かない。

## 02_Knowledge(副業を成功させるための知見)

副業ごとに分けずに1か所に貯める(どのエントリにも「どの副業で分かったことか」が書いてある)。個人の成長のためのものは`03_MyKnowledge`。

| フォルダ | 中身 |
|---|---|
| `01_ネタ/` | 発信に使えるネタ(ジャンル別) |
| `02_分析/` | 調べて分かったこと(伸びる型・競合・売れ筋・市場) |
| `03_成功と失敗/` | やってみて分かったこと(副業ごとに1ファイル) |
| `04_ノウハウ/` | 外から学んだ使える技術(ここな式=Threadsの書き方・発信の書き方=恋愛Xのデータから) |
| `_管理` | ナレッジ化の管理データ。人は触らない |

## 03_MyKnowledge(りゅーじ君のためのもの)

| フォルダ・ファイル | 中身 |
|---|---|
| `りゅーじのこと.md` | りゅーじ君の背景・考え方(まだ無い。質問しながら作る) |
| `01_AI/` | 操作メモ・用語メモ・設備メモ(AI学習用。このフォルダだけ専用の`CLAUDE.md`あり) |
| `02_自分の考え/` | りゅーじ君本人の言葉だけ |
| `03_使える知識/` | Claudeがまとめた自分用の知識。型+「りゅーじ君ならこう使う」 |

`03_使える知識/`の中はジャンルごと(`_管理`はナレッジ化の管理データ): `01_Psychology`(嫌われる勇気・こころが晴れるノート)・`02_Romance`(はやと式・LOVE理論・男女脳戦略・異性の心を上手に透視する方法)・`03_Sales`(乾式)

## 04_Projects(プロジェクト)

| プロジェクト | ファイル |
|---|---|
| `恋愛`(X→note) | `ルール.md`(ゴール・結果の測り方・立ち位置・話し方)・`X投稿.md`(構造・リサーチの条件)・`下書き.md`(まだ投稿してない案)・`投稿記録.md`(投稿した結果) |

## 毎朝の自動実行(`05_System/launchd/`)

| 時刻 | 名前 | やること | 状態 |
|---|---|---|---|
| 5:15 | `x-daily` | Xの7アカウントの新着を集める | 止めてる |
| 5:30 | `kw1ew-daily` | kw1ewのスクショを集めて厳選(collect) | 止めてる |
| 5:40 | `knowledge-agent-daily` | 新着をナレッジにする(my-knowledge・knowledge) | 止めてる |
| 6:00 | `knowledge-review-daily` | ナレッジのチェック(check) | 止めてる |

実行ログは`/Users/ryuji/sb-mac-logs/`(sb-macの外)に出る。

登録・解除はターミナルで:
```
launchctl load ~/Library/LaunchAgents/com.sbmac.<名前>.plist
launchctl unload ~/Library/LaunchAgents/com.sbmac.<名前>.plist
```
