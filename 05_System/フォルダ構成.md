# フォルダ構成(sb-macの地図)

どこに何があるかは、このファイルを見れば分かる。置き場所を変えたら、ここも一緒に直す。

## 一番上

| フォルダ・ファイル | 中身 |
|---|---|
| `CLAUDE.md` | 全体のルール・秘書エージェントの動き方 |
| `.claude/agents/` | サブエージェント4人の役割 |
| `.claude/skills/` | 手順書(スキル) |
| `01_Sources/` | 外から集めた生データ |
| `02_Knowledge/` | 配信用の知識(投稿のネタ) |
| `03_MyKnowledge/` | りゅーじ君のためのもの(自分の考え・自分用の知識・AI学習メモ) |
| `04_Projects/` | 発信などのプロジェクト(ルール・下書き・記録) |
| `05_System/` | 地図・組織図・TODO・更新履歴・毎朝の自動実行 |

## サブエージェント(`.claude/agents/`)

| 名前 | 仕事 |
|---|---|
| `research` | 調べる・分析する |
| `knowledge` | 知識にして溜める |
| `content` | 投稿などを作る |
| `qa` | 出す前にチェックする |

誰がどうつながるかは`05_System/AI組織図.md`。

## スキル(`.claude/skills/`)

| スキル | 何をする | 主に使う人 |
|---|---|---|
| `collect` | 情報収集(今はXの投稿型・スクショ型。媒体ごとにファイルが分かれてる) | 自動実行・秘書 |
| `transcribe` | 文字起こし(TikTok・YouTube・Kindle。媒体ごとにファイルが分かれてる) | 秘書 |
| `knowledge-build` | 生データを「自分用」と「配信用」のナレッジにする | Knowledge |
| `knowledge-check` | ナレッジの品質チェック | QA |
| `research` | 調査・分析(媒体ごとのアカウント探しと伸びる型の分析、自分の投稿の振り返り) | Research |
| `izuna-monthly` | イズナの交通費入力・カレンダー登録(月次) | 秘書 |

## 01_Sources(生データ)

| フォルダ | 中身 |
|---|---|
| `01_Kindle/data/<本>/本文.md` | Kindle本のOCR全文 |
| `02_X/data/@<アカウント>/posts.json` | Xの投稿(7アカウント) |
| `02_X/data/@kw1ew/スクショ/` | kw1ewの会話スクショ(厳選済み) |
| `02_X/共通点メモ.md` | 複数アカウントに共通する経験則(Knowledgeと呼ぶには根拠が弱いもの) |
| `03_TikTok/data/@<アカウント>/transcripts/` | TikTokの文字起こし |
| `04_YouTube/data/@<チャンネル>/transcripts/` | YouTubeの文字起こし |
| `05_Instagram/` | Instagram用(まだ空。集め始めたらここに入れる) |
| `06_Threads/` | Threads用(まだ空。集め始めたらここに入れる) |

各フォルダの`scripts/`は収集・文字起こしのプログラム。使い方はスキル(`collect`・`transcribe`)に書いてある。生データの分析結果はここには置かない。

## 02_Knowledge(配信用の知識)

投稿のネタ。ジャンルごとのフォルダに、情報源ごとに1ファイル。Contentはここからネタを選ぶ。

| フォルダ | 中身 |
|---|---|
| `01_Marketing` | 書き方・構成の技術(ここな式)。どのジャンルの投稿でも使う |
| `_管理` | ナレッジ化の管理データ(`knowledge_meta.json`・`knowledge_progress.json`)。人は触らない |

恋愛などのジャンルのフォルダは、ナレッジを作り直す時にできる。

## 03_MyKnowledge(りゅーじ君のためのもの)

| フォルダ・ファイル | 中身 |
|---|---|
| `りゅーじのこと.md` | りゅーじ君の背景・考え方(まだ無い。質問しながら作る) |
| `01_AI/` | 操作メモ・用語メモ・設備メモ(AI学習用。このフォルダだけ専用の`CLAUDE.md`あり) |
| `02_自分の考え/` | りゅーじ君本人の言葉だけ(不安・ネガティブ思考への対処) |
| `03_使える知識/` | Claudeがまとめた自分用の知識。型+「りゅーじ君ならこう使う」 |

`03_使える知識/`の中はジャンルごと: `01_Psychology`(嫌われる勇気・こころが晴れるノート)・`02_Romance`(はやと式・LOVE理論・男女脳戦略・異性の心を上手に透視する方法)・`03_Sales`(乾式)・`04_Interior`(ICHi式)

## 04_Projects(プロジェクト)

| プロジェクト | ファイル |
|---|---|
| `content`(恋愛X→note) | `ルール.md`(全ルール)・`下書き.md`(まだ投稿してない案)・`投稿記録.md`(投稿した結果) |

新しいプロジェクトを始める時は`04_Projects/<名前>/ルール.md`を作る。

## 毎朝の自動実行(`05_System/launchd/`)

| 時刻 | 名前 | やること | 状態 |
|---|---|---|---|
| 5:15 | `x-daily` | Xの7アカウントの新着を集める | 止めてる |
| 5:30 | `kw1ew-daily` | kw1ewのスクショを集めて厳選(collect) | 止めてる |
| 5:40 | `knowledge-agent-daily` | 新着をナレッジにする(knowledge-build) | 止めてる |
| 6:00 | `knowledge-review-daily` | ナレッジのチェック(knowledge-check) | 止めてる |

実行ログは`/Users/ryuji/sb-mac-logs/`(sb-macの外)に出る。

登録・解除はターミナルで:
```
launchctl load ~/Library/LaunchAgents/com.sbmac.<名前>.plist
launchctl unload ~/Library/LaunchAgents/com.sbmac.<名前>.plist
```
