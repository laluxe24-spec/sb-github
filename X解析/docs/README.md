# X解析

X(Twitter)アカウントの投稿を分析・収集するプロジェクト。解析の目的によって2種類のデータを分けて管理している。

- `docs/` : 共通ドキュメント(このREADME、各操作メモ)
- `scripts/` : 収集・ログイン用のPlaywrightスクリプト(共通)
- `screenshot_accounts/<アカウント名>/` : **DM会話のスクショ**を収集するタイプ
  - `スクショ/` : 厳選済みのスクショ画像(連番.jpg)
  - `manifest.json` : 各画像の元ツイートURL付きメタデータ
  - `会話文字起こし.md` : スクショの文字起こし・パターン分析
- `post_accounts/<アカウント名>/` : **ツイート本文(投稿テキスト)**を収集するタイプ
  - 投稿本文+URLを収集し、複数アカウント横断で共通点を分析する用途
