## 手順

### 1. ログイン(auth.jsonのセッションが切れている場合)
```
node login.js
```
ヘッドありのブラウザが開くので、ユーザー本人がその場でXにログインする。`auth_token`のCookieを検知したら自動で `auth.json` に保存して終了する(最大10分待機)。

### 2. 次のN件を収集する
```
node collect_media.js 100
```
- `https://x.com/kw1ew/media?filter=photo` のグリッドをスクロールしながら、`processed_ids.json` に無い(=未取得の)写真投稿を新しいものから順にN件集める
- ダウンロードした画像は `scripts/screenshots_batchN/`(生データ、まだ絞り込み前)に保存され、`processed_ids.json` が更新される

### 3. 絞り込み(3段階)
`scripts/screenshots_batchN/` の画像を1枚ずつ見て、以下の基準で仕分ける。

**残す**
- 実際の2人の会話で、口説き・ラポール構築のテクニックを示しているもの(オープニング、テンポの良い掛け合いなど)。地の文の画面キャプチャ(LINE/DM等のトーク画面そのもの)であること。

**除外**
- 電話を手に持って撮影した写真(スクショではなく撮影写真)
- 本の表紙・ニュース動画・食事写真など、チャット画面と無関係な画像
- 性的な体験報告(「報告です」「結果◯」形式、性的内容の詳細な描写、ヌード・際どい写真を含むもの)
- 感想・レビュー(お客さん・受講生が講座や本人を褒めているだけのメッセージ)
- ダウンロード失敗(空/破損)ファイル

判断に迷う場合は「実際の口説き会話のテクニック例になっているか」を基準にする。

### 4. kw1ew/ に統合する
1. 絞り込み後に残った画像を `kw1ew/` にコピーする
2. `kw1ew/` 内の既存ファイルの最大番号(現在065)の続きから連番を振り直す(例: 066.jpg, 067.jpg…)
3. `kw1ew/manifest.json` に `{file, tweet_url}` の形式で追記する(元のバッチのmanifest.jsonからtweet_urlを引く)
4. `scripts/screenshots_batchN/` の生データは用済みなので削除してよい

### 5. 完了後
- このファイルの「現在の状態」を更新する(最新の連番の最大値など)
